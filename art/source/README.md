# Corgi bite pose source art

The seven `corgi-bite-*-concept.png` images are full-body pose concepts generated from this game's original corgi run/bark and outfit run sprites. They contain four right-facing poses: brace, lunge, snap/land, recoil.

Run `node scripts/build-corgi-bite-sprites.mjs` to produce the 448×128 transparent game spritesheets. Run the same command with `--check` to compare generated bytes with the committed assets. The build script aligns feet to the atlas baseline, uses nearest-neighbor sampling, and removes bright eye catchlights to retain the original corgi design.
