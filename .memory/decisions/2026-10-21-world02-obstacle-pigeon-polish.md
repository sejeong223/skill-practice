# Decisions: 월드 2 장애물과 비둘기 연출 조정

- Date: 2026-10-21 (Asia/Seoul)
- Status: 사용자 요청과 기존 코드 확인으로 확정

## D01. 장애물

- **사용자 선택**: 잠자는 고양이를 조금 줄여 통과하기 쉽게 한다. 포카칩 봉지는 최초 제작한 주황 봉지(`e7d9939`)처럼 바닥에 구겨져 낮게 놓인 자세를 쓴다. 지금의 흰색·빨간색·파란색 포카칩 디자인과 세로로 읽는 글자는 유지한다.
- **코드 확인으로 확정**: 고양이의 화면 크기를 `128×75 → 112×66`, 충돌 영역을 `62×32 → 52×28`px로 조정한다. 할퀴기 프레임에도 같은 크기를 적용한다. 최초 주황 봉지를 자세 참조, 기존 포카칩 봉지를 디자인 참조로 새 투명 픽셀 아트 `empty-snack-bag-ground.png`를 만들고 에셋 키는 유지한다. PNG의 투명 여백을 고려하여 표시 크기 `175×95`, 원점 y `0.88`, 충돌 영역 `42×18`px로 바닥 `groundY:504`에 맞춘다.
- **근거**: 기존 포카칩 PNG의 높이만 줄인 시안과 세로로 긴 새 이미지 시안은 여전히 서 있는 봉지처럼 보였다. 최초 주황 봉지의 구겨진 실루엣을 실제 자세 기준으로 삼아야 한다.

## D02. 비둘기

- **사용자 선택**: 착지 위치를 미리 알려 주는 바닥 표시를 없앤다. 한 마리가 같은 자리 근처에 세 번 배설하지 않고 비행하면서 서로 구분되는 세 위치에 떨어뜨린다.
- **코드 확인으로 확정**: 기존 비행 구간과 2초 재등장 주기를 유지한다. 각 비둘기의 낙하 위치는 구간 중심 기준 `+84`, `0`, `-84`px이다. 바닥 경고 그래픽은 만들지 않는다. 실제 똥 스프라이트, 충돌, 착지 후 0.3초 자국은 유지한다.
- **근거**: 기존 44px 간격은 화면에서 한 자리처럼 보였다. 84px 간격은 코기 충돌 폭 72px보다 넓고 기존 장애물과 회피 여유가 남는다.

## D03. 범위

- 현재 이 적용 대상은 `world-02-stage-1`이다. 후속 스테이지와 비둘기 2초 주기는 바꾸지 않는다.
