# Decisions: 월드 2 장애물과 비둘기 연출 조정

- Date: 2026-10-21 (Asia/Seoul)
- Status: 사용자 요청과 기존 코드 확인으로 확정

## D01. 장애물

- **사용자 선택**: 잠자는 고양이를 조금 줄여 통과하기 쉽게 한다. 포카칩 봉지는 세로로 인쇄된 기존 디자인과 읽는 방향을 그대로 유지하면서 모래 바닥에 납작하게 놓인 모습으로 보이게 한다. 가로로 회전한 봉지 이미지는 사용하지 않는다.
- **코드 확인으로 확정**: 고양이의 화면 크기를 `128×75 → 112×66`, 충돌 영역을 `62×32 → 52×28`px로 조정한다. 할퀴기 프레임에도 같은 크기를 적용한다. 포카칩은 기존 원본 PNG를 사용하고 화면에서 세로 방향만 눌러 바닥에 펼쳐진 투영처럼 표현한다. 표시 크기는 `80×36`, 충돌 영역은 `42×18`px로 조정한다. 바닥 접점은 원래 `groundY: 504`를 유지한다.
- **근거**: 기존 PNG의 글자와 그림은 이미 세로 방향으로 완성돼 있고, `World02ObstacleSystem`은 장애물 데이터의 `displaySize`를 화면에 적용한다. 새로 만든 가로 봉지 이미지는 사용자 의도와 다르므로 제외한다.

## D02. 비둘기

- **사용자 선택**: 착지 위치를 미리 알려 주는 바닥 표시를 없앤다. 한 마리가 같은 자리 근처에 세 번 배설하지 않고 비행하면서 서로 구분되는 세 위치에 떨어뜨린다.
- **코드 확인으로 확정**: 기존 비행 구간과 2초 재등장 주기를 유지한다. 각 비둘기의 낙하 위치는 구간 중심 기준 `+84`, `0`, `-84`px이다. 바닥 경고 그래픽은 만들지 않는다. 실제 똥 스프라이트, 충돌, 착지 후 0.3초 자국은 유지한다.
- **근거**: 기존 44px 간격은 화면에서 한 자리처럼 보였다. 84px 간격은 코기 충돌 폭 72px보다 넓고 기존 장애물과 회피 여유가 남는다.

## D03. 범위

- 현재 이 적용 대상은 `world-02-stage-1`이다. 후속 스테이지와 비둘기 2초 주기는 바꾸지 않는다.
