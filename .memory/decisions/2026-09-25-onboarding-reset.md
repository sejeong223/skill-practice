# Decisions: 최초 오프닝과 저장 진행 초기화

- Date: 2026-09-25
- Status: Confirmed

## D01. 오프닝과 이름 입력 표시 시점
- **Chosen**: 저장된 진행을 유지하며, 오프닝과 이름 입력은 온보딩을 완료한 뒤 재접속/새로고침에서 다시 표시하지 않는다.
- **Rationale**: 사용자가 기존 사망 횟수와 저장 진행을 보존하기로 정했다. 온보딩 완료를 별도 저장 상태로 남겨 진입 화면과 저장 상태를 일치시킨다.

## D02. 저장된 온보딩 상태의 호환
- **Chosen**: `ProgressState.onboardingCompleted`를 추가한다. 기존 저장은 `seenCutsceneIds`에 `intro-home`이 있으면 완료로 간주한다.
- **Rationale**: 기존 세이브를 초기화하지 않고 기존 사용자가 이미 본 오프닝을 건너뛸 수 있다. 저장 키는 유지하고 envelope schema만 2로 올린다.

## D03. 수동 초기화
- **Chosen**: 일시정지 옆 픽셀 회전 아이콘을 누르면 확인 창을 띄우고, 확인 시 저장 데이터 전체를 지운 뒤 새로고침한다.
- **Rationale**: 실수로 지우는 일을 막으면서 이름, 사망 횟수, 코인, 해금, 아이템, 조작키 등 단일 저장 프로필을 한 번에 초기화한다.
