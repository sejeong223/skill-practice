# Decisions: 월드 3 공사장 인트로

- Date: 2026-10-28
- Status: Confirmed
- Scope: 월드 2 인트로의 진행 방식을 바탕으로 월드 3 인트로를 설계한다. 이 인터뷰에서는 구현 코드를 수정하지 않는다.

## D01. 진행 방식과 대본

- **Chosen (user)**: 월드 2처럼 전용 화면에서 나레이션과 코기 대사가 순서대로 자동 진행되며, 마지막 대사가 끝나면 월드 3의 첫 스테이지로 넘어간다. 아래 여섯 줄의 문구와 순서를 그대로 사용한다.
- **Derived from code**: 기존 `WORLD02_ENTRANCE_CUTSCENE`처럼 여섯 개의 beat를 두고 글자 수에 맞춰 각 표시 시간을 정한다. 이미 본 인트로에만 건너뛰기를 허용하고, 종료·건너뛰기 시 `seenCutsceneIds`에 기록한다. 마지막에는 화면을 어둡게 전환한 뒤 `world-03-stage-1`을 시작한다.
- **Rationale**: 월드 2 인트로의 익숙한 진행 흐름을 유지하면서 사용자가 확정한 대사를 빠짐없이 보여준다.

### 확정 대본

1. 나레이션: 지옥의 놀이터를 헤쳐 나온 코기의 앞에 웅장한 위엄을 드러낸 곳은... 철근과 시멘트 가루가 춤추는 위험천만 공사장.
2. 나레이션: 사방에서 들려오는 진동드릴 소음과 굴착기의 굉음 속에서, 냥아치들은 이미 자신들만의 요새를 구축하고 있었다.
3. 코기: 콜록콜록! 이 먼지 구덩이에 시멘트 냄새까지... 강아지 호흡기 다 망가지겠네!
4. 나레이션: 시뻘건 철근이 사방으로 널려 있고, 발 밑은 아직 굳지 않은 촉촉한 시멘트가 코기의 짧은 다리를 유혹하고 있었다.
5. 나레이션: 누가 봐도 냥아치들의 덫이지만, 15cm 다리의 왕갈비뼈 집착 본능은 위험을 아예 지워버렸다.
6. 코기: 먼지 좀 마시면 어때! 내 갈비뼈만 찾으면 그만이다, 기다려라 냥아치들!

## D02. 전용 그림

- **Chosen (user)**: 오후 3~4시의 공사장 전경, 먼지에 기침하는 코기, 결의를 다지는 코기 등 전용 픽셀 그림 세 장을 새로 만든다.
- **Chosen (user)**: 두 코기 초상화는 월드 2와 같이 기본 코기 모습으로 만든다. 장착 중인 의상은 인트로 초상화에 반영하지 않는다.
- **Derived from prior user feedback**: 기존 코기의 색과 얼굴 비율을 기준으로 하며 눈에 흰 안광을 넣지 않는다.
- **Rationale**: 월드 2와 같은 배경·표정 전환 구조를 쓰되 월드 3의 오후 공사장 분위기와 기침·결의 장면을 분명하게 보여준다.

## D03. 진입 경로와 재방문

- **Chosen (user)**: 일반 진행에서 월드 2 물기 해금 후 월드 3에 처음 들어갈 때, 그리고 개발 모드에서 월드 3에 처음 들어갈 때 인트로를 재생한다. 이미 본 개발 모드 재시작은 스테이지로 바로 들어간다.
- **Derived from code**: `seenCutsceneIds`에 `world-03-intro`가 없는 월드 3 첫 진입을 판별한다. 일반 저장 데이터를 불러와 월드 3 첫 스테이지로 복귀하는 경로도 같은 판별을 적용하고, 이미 본 인트로는 바로 스테이지로 보낸다.
- **Rationale**: 월드 3에 도달한 경로와 관계없이 첫 소개를 보여주되 이후 재시작에서는 반복을 피한다.

## D04. 배경음악과 공사장 효과음

- **Chosen (user)**: 기존 월드 3 배경음악과 새로 만든 드릴·굴착기 효과음을 함께 쓴다. 효과음은 픽셀 게임에 맞는 짧고 뚜렷한 합성음으로 제작한다.
- **Chosen (user)**: 드릴 떨림과 굴착기 저음을 두 번째 나레이션에 낮은 음량으로 짧게 배치한다. 코기 대사가 시작되기 전에 효과음을 끝내고, 배경음악은 인트로 동안 이어지게 한다.
- **Derived from code**: 현행 beat 모델의 `soundCue`는 한 번에 하나이므로 같은 장면에서 두 효과음을 재생할 타이밍을 설계해야 한다. `AudioManager`는 현재 `StageScene`에서만 생성되므로 새 인트로 장면에서도 음악·효과음 재생과 종료 시 정리를 연결해야 한다. 새 오디오 자산은 프리로드·사운드 키·출처 기록에 등록한다.
- **Rationale**: 공사장 소음을 실제로 들려주되 자막과 코기 대사의 이해를 방해하지 않는다.

## D05. 낡은 월드 3 맵 항목 정리

- **Chosen (user, planning follow-up)**: 실제 파일이 없는 선택형 `world-03-map-placeholder` manifest 항목을 이번 인트로 계획의 자산 Task에서 정리한다.
- **Derived from code**: `/assets/pixel/maps/world-03/world-03-stage-1.json`은 존재하지 않고 해당 manifest 키를 참조하는 구현 코드도 없다. 다른 월드 3 맵·배경 자산은 유지한다.
- **Rationale**: 새 인트로 자산을 등록하면서 혼동을 주는 죽은 항목만 함께 제거한다.

## 계획에서 다룰 코드 연결

- `src/game/data/cutscenes/worlds.ts`의 `world-03-intro`는 현재 한 줄짜리 임시 대본이다. 이를 중복 인트로를 만들지 않고 확정 대본으로 교체한다.
- `World02EntranceScene`의 화면 구성과 이벤트 계약을 참고해 월드 3 전용 장면을 추가하고, 장면 등록·그림 프리로드·자막 표시·HUD 숨김을 연결한다.
- 월드 2 물기 해금 직후와 `PreloadScene`의 개발·일반 복귀 경로가 현재 월드 3 스테이지로 직행하므로 첫 방문 판별과 인트로 진입을 연결한다.
- 인트로 재생, 스킵 권한, 본 기록, 일반·개발 진입, 음악·효과음 수명 주기를 검증하는 테스트를 계획한다.

## 인터뷰 중 확인한 인접 사항

- 과거 월드 3 디자인 계획은 인트로 연결을 의도적으로 범위에서 제외했다. 이번 요청은 월드 3 인트로의 신규 설계이므로 그 제외 범위를 갱신한다.
- 월드 2 인트로에는 전용 오디오 관리자가 없다. 새 인트로에서 음악과 효과음을 재생하려면 장면 수명에 맞는 오디오 소유자를 정해야 한다.
