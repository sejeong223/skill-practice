# Decisions: 개발 서버 월드2 시작 복원

- Date: 2026-10-26 (Asia/Seoul)
- Status: 사용자의 새 요청과 기존 월드2 개발 시작 결정에 따라 확정

## D01. 적용 범위

- **사용자 요청**: 개발 중 게임을 열 때 첫 인트로와 월드1의 반복 플레이를 건너뛰고 월드2에서 시작한다. 이 동작은 개발 중에만 적용한다.
- **선택**: `process.env.NODE_ENV === "development"`에서만 월드2 시작 정책을 적용한다. 프로덕션은 기존 저장 복원 및 새 저장 인트로 경로를 유지한다.
- **근거**: 기존 진입 코드는 이미 `NODE_ENV`를 기준으로 개발용 시작 경로를 분기한다.

## D02. 개발 시작 지점과 컷신

- **선택**: 월드1 집 인트로, 이름 입력, 월드2 진입 컷신을 모두 건너뛰고 월드2 1스테이지 게임플레이로 바로 간다. 개발 환경의 시작 때만 컷신을 건너뛰며 컷신 데이터와 일반 월드 전환 흐름은 수정하지 않는다.
- **근거**: 사용자가 월드2 진입 컷신도 건너뛰고 게임플레이를 바로 시작하도록 명확히 선택했다.

## D03. 개발 진행 상태

- **선택**: 개발 모드의 시작 진행 상태는 기존 저장의 코인·장비·사망·클리어 데이터를 보존하면서 `onboardingCompleted`, 월드1 보스 완료, 짖기 해금, 월드2 선택과 첫 인트로 시청 표시를 보충한다. 중복 값은 추가하지 않는다.
- **근거**: 첫 스테이지로 바로 진입하면서 월드 선택을 사용할 수 있게 하는 기존의 검증된 정책을 재적용한다. 프로덕션에서는 입력 진행 상태를 변경하지 않는다.

## D04. 범위 밖

- 저장 스키마, 게임 밸런스, 일반 사용자의 시작 화면, 월드2 후속 스테이지 구성은 변경하지 않는다.
