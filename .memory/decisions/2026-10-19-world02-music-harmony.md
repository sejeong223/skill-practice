# Decisions: 월드 2 음악 화음 정렬

- Date: 2026-10-19
- Status: Superseded by [월드 2 기존 음악 복원](./2026-10-19-world02-original-music-restore.md)

## D01. 확인된 원인
- **Chosen**: 월드 2 기본 음악 `world-02-amusement`의 베이스·멜로디를 코드에 정의된 화음 진행 `F → C → Dm → Bb`와 맞춘다.
- **Rationale**: `AudioManager`는 음악 교체 시 이전 Tone 시퀀스를 정리하고, 월드 2 진입 컷신은 음악을 시작하지 않는다. 반면 현재 2박마다 바뀌는 화음과 1박마다 바뀌는 베이스가 맞지 않는다. 특히 C 위에 D/A, Dm 위에 Bb/F, Bb 위에 C/C가 연주된다.

## D02. 수정 범위와 검증
- **Chosen**: 월드 2 기본 곡의 음표만 바로잡고, 월드 1에서 월드 2로 전환할 때 활성 시퀀스가 한 곡분인지 검증한다.
- **Rationale**: 다른 월드 음악까지 바꾸면 이번 확인 범위를 벗어난다. 곡의 레이어 수와 화음 일치를 각각 검증해야 겹침과 불협화음을 구분할 수 있다.

## Existing constraint
- 실제 음악 파일은 없고 Tone 신시사이저가 `melody`(8분음표), `chords`(2분음표), `bass`(4분음표)를 반복 재생한다. 월드 2는 화음 1개마다 멜로디 4음과 베이스 2음이 대응한다.
