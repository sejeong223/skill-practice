# Decisions: 월드 1 일시정지·음악·체크포인트 피드백

- Date: 2026-10-12 (Asia/Seoul)
- Source: 사용자의 최신 memory-plan 요청 4개, 앞서 제공한 보스전 화면, 현재 작업 트리 읽기/atlas 이미지 확인.
- Scope: 계획 문서만 갱신. 이 기록은 사용자 요구와 코드 확인으로 정한 구현 선택을 구분하며 추가 인터뷰를 했다는 뜻이 아니다.

## User Requirements

1. 보스전에 있는 원을 확인하고 제거한다.
2. 일시정지하면 BGM도 멈추고 중앙 ‘일시정지’ 문구를 높은 z-index와 반투명 검은 배경 위에 표시한다.
3. 월드/보스마다 다른 BGM을 사용한다. 현재 범위는 월드 1로, 귀엽고 평화로운 일반 곡과 긴박함이 아주 조금 느껴지는 보스 곡을 기존 도구로 만든다.
4. 체크포인트 사각형을 깃발 이미지로 교체한다. 기존 에셋이 없으면 비슷한 스타일로 생성하며, 지나서 활성화될 때 ‘띠리링’ 효과음을 추가한다.

## Repository Findings and Implementation Decisions

| 항목 | 확인한 사실 | 계획의 선택 |
| :--- | :--- | :--- |
| 보스전 원 | createSegment가 보스에도 코인3개를 넣고 기본 표현은 노란 ellipse다 | 월드 1 보스 coins 목록만 비워 생성/획득 판정 함께 제거 |
| 일시정지 | runtime/physics만 멈추며 Scene update가 재개 입력을 처리한다 | AudioManager.setPaused 연결, transport 위치 보존, gain으로 잔향 차단 |
| 중앙 표시 | HUD z3/컷신8/사망10/초기화창20 | 프레임 직접 자식 오버레이 z15, 검은색60%, 중앙 제목과 계속하기 |
| 음악 도구 | Tone.js Synth/Sequence와 Web Audio 합성을 사용한다 | 동일 도구로 신규16마디 루프2개, 새 외부 서비스 도입 없음 |
| 음악 키 | 오프닝 cat-entry도 world-01-alley를 쓴다 | 오프닝 보존, world-01-peaceful/world-01-calico 신설 |
| 일반 구간 소리 | StageScene AudioManager는 월드 1 보스에만 있다 | 일반 구간도 Scene당1개 생성하고 stage-started로 음악 선택 |
| 깃발 이미지 | props atlas fake-checkpoint 프레임에 완성된 픽셀 깃발이 있다. 직접 이미지 확인함 | 실제 체크포인트용 별칭으로 재사용, 현재 신규 생성 불필요 |
| 체크포인트 판정 | 저장은 ID/속성/CheckpointSystem이 결정하고 이미지명과 무관하다 | 숨긴 기존 Rectangle 판정 유지, 별도 깃발을 수명주기에 연결 |
| 차임 | 이벤트 구독은 있으나 일반 Scene에 관리자가 없고 기존 합성은 사각파2음이다 | 최초 성공 활성화에만 sine 상승3음, 자동 복원은 silent |

초기 BPM/음량/음표, 60% 투명도와 z15, 깃발 크기, 차임 주파수는 구현 초안이며 청음/화면 검증에 따라 조정할 수 있다. 이 세부 수치를 사용자에게 직접 승인받았다고 표현하지 않는다.

## Preservation and Deferred Work

- 현재 작업 트리의 보스 원래 타일 바닥, 공용 Tone 컨텍스트에 연결한 bowl-clang, persistent unlock 변경을 보존한다.
- 이전 gameplay-refinement T01~T05 완료/한국어 커밋 이력을 유지하고 새 포인터만 새 T01로 설정한다.
- 예전 compact T03의 체크포인트 깃발만 새 T03으로 위임한다. 당시 신규 낮 색상 SVG 제안은 실제 확인한 기존 테마의 깃발 재사용으로 구체화한다. 출구/보스 arena/하트는 자동 흡수하지 않는다.
- 월드 2~5 음악 매핑은 유지하되 이번에 새 곡을 전부 제작하지 않는다. 미래 월드 보스 곡도 별도 키로 넣을 수 있게 매핑을 분리한다.
- 상점/옷/클리어한 월드 재도전은 후속 계획. 정상 반복 수급이 마련되기 전 같은 코인의 사망 후 재획득을 제한하지 않는다.
- 별도 인접 개선은 추가하지 않았다. 초록 수집품/출구 등 다른 임시 객체를 ‘노란 원’ 요청에 묶어 삭제하지 않는다.
