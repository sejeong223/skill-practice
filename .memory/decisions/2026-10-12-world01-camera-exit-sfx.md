# 결정: 대사 카메라·출구·체크포인트·새 효과음

- 사용자 수정 요청에 따라 계획 후 바로 순차 구현한다. 이전처럼 Task별 한국어 커밋과 자동 검사 수정을 이어간다.
- 보스 도입/클리어 대사에서 축소 없이 현재 화자(코기/삼색이)의 실제 위치로 카메라를 이동한다. 대사 종료/건너뛰기 시 원래 추적을 복원한다.
- 출구 사각형을 숨기고 일반 스테이지의 오른쪽 끝에서 코기가 완전히 화면 밖으로 나가면 자동 진행한다. 보스는 쓰러뜨려야 완료된다.
- 체크포인트 판정은 보이지 않게 하고 실제 저장 지점에는 깃발만 표시한다. 부활 위치는 접촉 순간의 플레이어 좌표 대신 깃발의 안전한 지면 좌표를 저장한다. 아직 밟지 않은 체크포인트/출구를 부활 지점으로 쓰지 않는다. 보스 실패 후 4단계 깃발 복귀는 유지한다.
- 맵 반복 질문은 데이터 근거를 설명한다. 1/3은 같은 평지·기본 배경·간식 위치, 2/4는 유사한 계단형 지형이다. 2/4 중경 이미지는 서로 다른 파일이며 기믹도 다르다. 맵 재설계는 이번에 요청받지 않았다.
- 간식 획득과 체크포인트 효과음을 새 WAV 자산으로 제작한다. 기존 기본음 재사용 대신 각각 동전 짤랑/상승하는 띠리링을 직접 합성한다. 실시간 BGM과 같은 Tone AudioContext에서 버퍼를 재생하여 Phaser 컨텍스트의 별도 정지 영향 없이 들리게 한다.
- 실제 획득 성공 이벤트만 돈 소리를 발생시킨다. 저장 복원/잔액 초기 알림/죽음은 획득음 대상이 아니다. 체크포인트는 최초 실제 활성화 한 번, 자동 복원은 무음이다.
- 지갑·현재 재획득 정책·방패3회·HP10·사모예드5마리·일시정지 동작은 보존한다.
