# Decisions: 월드 2 비둘기 배설 간격 완화

- Date: 2026-10-21 (Asia/Seoul)
- Status: 사용자 요청과 기존 코드 확인으로 확정

## D01. 한 비둘기의 배설 간격

- **사용자 선택**: 현재보다 똥을 싸는 간격을 약 0.3초 늘린다.
- **코드 확인으로 확정**: 이는 한 비둘기의 연속된 세 배설 사이 간격으로 해석한다. 현재 낙하 지점 간격은 84px이고 비행 속도는 160px/s라 `84 / 160 = 0.525`초다. 세 구간 모두 `birdSpeedX: 102`px/s로 바꾸면 `84 / 102 ≈ 0.824`초로, 약 0.299초 늘어난다.
- **근거**: 낙하 x좌표를 바꾸면 주변 장애물과의 회피 여유가 달라진다. 비행 속도만 바꾸면 기존 세 낙하 지점은 유지할 수 있다.

## D02. 유지할 동작과 예상 영향

- 비둘기 새 개체의 등장 간격 `WORLD02_PIGEON_SPAWN_INTERVAL_MS = 2000`, 똥의 수직 낙하 속도 `droppingSpeedY = 770`, 낙하 지점 오프셋 `[84,0,-84]`, 접촉 즉사·일시정지·체크포인트는 유지한다.
- 한 마리의 비행 시간이 길어져 화면에 비둘기가 더 겹칠 수 있다. 2초 등장 주기는 사용자 요청 범위 밖이므로 바꾸지 않고, 동시 비행 중 충돌·정리가 계속 동작하는지 확인한다.
