## Source

- 사용자가 2026-10-14에 제공한 여섯 문장을 문구·문장부호·화자 표기까지 그대로 사용한다.
- [기존 월드 2 진입 결정](./2026-10-14-world02-playground-entrance.md)의 이미지 3장, 월드 1 클리어 버튼 뒤 자동 재생, 첫 관람 건너뛰기 제한, 재관람 건너뛰기, 완료 후 `world-02-stage-1` 진입은 유지한다. 이번 원고가 기존 마지막 대사 `....가자!`를 대체한다.

## Technical Decisions

- 기존 `world-02-intro` 저장 ID와 세 이미지 자산을 그대로 사용한다. 이미지·배경·코기 얼굴은 새로 만들거나 교체하지 않는다.
- 문장 하나를 `CutsceneBeat` 하나로 표현해 총 6비트로 자동 진행한다. 나레이션은 `narration` 필드, 코기는 `dialogue: [{ speaker: "corgi", text }]`를 사용한다. 문장 4의 대괄호는 화면에 글자 그대로 표시한다.
- 장면 전환은 비트 0·2·4에서만 수행하고 같은 이미지의 두 번째 문장에서는 초상화·카메라 움직임을 다시 시작하지 않는다.
- 원고가 기존 한 줄보다 길어지므로 자동 표시 시간을 문장별로 늘린다. 첫 관람의 컷신 전체 건너뛰기는 계속 막고, 재관람 건너뛰기는 유지한다. 마지막 문장 후 기존 400ms 페이드를 거쳐 플레이를 시작한다.
- 기존 대사창 이미지를 모든 비트에서 사용한다. 긴 문장이 데스크톱과 좁은 화면에서 잘리지 않도록 텍스트 크기·줄바꿈·프레임 높이를 함께 조정한다.
