# Decisions: 보스전 짖기 쿨타임과 경고 연출

- Date: 2026-10-19
- Status: Confirmed (요청·추가 답변 확정, 미지정 수치는 아래 구현 기본값)

## D01. 짖기 쿨타임과 HUD
- **Chosen (User)**: 짖기 쿨타임은 10초. 보스전 화면 왼쪽 아래에서 남은 시간을 확인한다.
- **Chosen (Implementation, 추가 요청 반영)**: 스킬 정의의 공통 쿨타임을 10000ms로 변경한다. HUD는 보스전·일반 장애물 구간의 플레이 중 짖기가 해금된 경우에 `짖기 [설정 키]`와 `10.0초 → 0.1초 → 준비` 및 작은 진행 막대를 표시한다.
- **Rationale**: 현재 `SKILL_DEFINITIONS.bark.cooldownMs`는 900ms이고 `GameShell`은 HUD에 빈 `cooldowns={{}}`를 넘긴다. 게임의 실제 남은 시간으로 UI를 갱신해야 한다.

## D02. 세 번째 사용
- **Chosen (User)**: 3번째 짖기마다 큰 화면 흔들림과 중앙 경고를 표시한다.
- **Chosen (Implementation)**: 같은 보스 도전에서 `SkillSystem.use()`가 성공한 사용만 3·6·9…회로 센다. 경직 명중 여부나 사용 사이 시간 제한은 없다. 거절된 입력은 세지 않는다. 사망·재도전·장면 이동 시 횟수와 쿨타임은 초기화하고 저장하지 않는다.
- **Chosen (User follow-up)**: 사레는 화면 흔들림·경고 문구만 표시한다. 이동과 기존 짖기 효과를 유지한다. 추가 이동 잠금·체력 피해·추가 쿨타임은 없다.
- **Chosen (Implementation)**: 게임 카메라를 800ms, 강도 0.035로 흔든다. 중앙 문구와 HUD는 카메라 밖 React 화면에 두어 읽을 수 있게 유지한다.

## D03. 경고 문구와 공통 표시
- **Chosen (User)**: 제목 앞 경고 기호와 아래 문구를 정확히 표시한다. 제목과 본문을 분리하고 모바일에서 본문 줄바꿈을 허용한다.

```text
⚠ 3연속 짖기 발동!
너무 세게 짖은 나머지 사레에 들리고 말았습니다!
```

```text
⚠ 밥그릇 소리 경보!
밥 소리인 줄 알고 동네 강아지들이 정모하러 왔습니다!
```

- **Chosen (User)**: 두 경고 모두 아주 옅은 반투명 빨간색 배경으로 코기의 대치 상황이 잘 보여야 한다.
- **Chosen (Implementation)**: 게임 영역 전체에 `rgb(239 68 68 / 8%)` 한 겹을 2500ms 표시한다. 진한 패널·검정 딤·블러는 없다. 글자는 불투명하고 얇은 외곽 그림자로 읽기 쉽게 한다. 경고가 겹치면 최신 경고로 교체하고 불투명도를 누적하지 않는다.
- **Rationale**: 8%는 전투 장면을 보존하는 시작값이다. 실행 시 실제 화면으로 확인하되, 밝기가 부족하다는 이유로 10%를 넘기지 않는다.

## D04. 밥그릇 소환과 적용 범위
- **Chosen (User)**: 월드 1에서 밥그릇으로 3회 방어해 강아지가 몰려올 때 중앙 경고를 표시한다.
- **Chosen (Codebase)**: 이미 `DefenseToolSystem → bowl-broken → StrayDogEvent → stray-dog-surge`로 소환한다. 월드 1 보스에서 실제 `stray-dog-surge`를 받아 경고만 연결하며 방어·소환을 추가 발생시키지 않는다.
- **Chosen (Implementation, 추가 요청 반영)**: 짖기 사용·HUD는 normal/boss 모두 지원한다. 세 번째 사용 경고·흔들림은 기존 보스전 범위를 기본값으로 유지한다. 일반 구간 경고 확장 여부를 추가 선택 질문으로 보냈으나 계획 작성 시점에 답변이 없어 기존 범위를 유지했다(사용자의 추가 확정 답변으로 기록하지 않는다). 현재 보스 효과 검증은 월드 1 삼색이 재도전에서 수행한다.

## D05. 시간과 수명
- **Chosen (Implementation)**: 짖기 쿨타임은 플레이 중 누적되는 시간, 경고는 플레이 중 delta로 진행한다. 일시정지·월드 선택 중 모두 멈춘다. 일시정지 시 진행 중 카메라 흔들림은 종료하고 재개 시 다시 흔들지 않는다. 경고의 남은 시간은 재개한다.
- **Chosen (Implementation)**: 사망·승리 대사·스테이지 전환·shutdown에서 경고와 흔들림을 즉시 정리한다. UI는 입력을 막지 않는다.
- **Rationale**: 현재 일시정지는 Physics와 runtime만 멈추며 `StageScene.update(time)`의 절대시간은 계속 간다. 그대로 쿨타임을 계산하면 일시정지로 10초를 건너뛸 수 있다.

## Superseded detail
- 2026-10-14 짖기 해금 결정의 스킬 쿨타임 900ms만 이번 10000ms로 대체한다. 삼색이 경직 1200ms·범위 320px·재경직 제한 3000ms는 그대로 사용한다.

## D06. 짖는 코기 이미지
- **Chosen (User)**: 기존 코기의 모습에서 입을 벌린 새 이미지 한 장을 만들어 누구나 짖는 동작으로 알아볼 수 있게 한다.
- **Chosen (Codebase)**: 실제 `corgi-run.png`는 112×128 프레임 4개다. `corgi-bark.png`는 없으며 manifest의 32×48×4 optional 설정은 플레이 코기와 맞지 않는다. PlayerAnimator는 달리기만 처리한다.
- **Chosen (Implementation)**: 실행 단계에서 imagegen 스킬로 실제 플레이 스프라이트를 참고해 오른쪽을 보는 네 발 코기 한 장을 제작한다. 황갈색·흰색 털, 귀·눈·몸통 비율과 픽셀 선을 유지하고 입 안이 확실히 보이는 열린 입과 살짝 든 주둥이로 짖음을 표현한다. 투명 PNG 112×128, 발 기준 99px, `corgi-bark` image/required로 등록한다. 앞선 인트로용 앉은 정면 이미지와는 다른 플레이 에셋이다.
- **Chosen (Implementation)**: 사용 성공 후 450ms 보여 주고 현재 이동 상태로 복귀한다. 이동·점프·좌우 반전·충돌 크기를 유지한다. 일시정지는 표시 타이머를 멈추고 사망·재도전·장면 종료는 정리한다.

## D07. 실제 짖기 입력과 효과음
- **Chosen (User)**: 짖기 버튼을 누르면 짖는 소리가 나야 한다.
- **Chosen (Codebase)**: `SkillSystem.use` 성공 시 `skill-used` 이벤트가 나지만 AudioManager는 이를 구독하지 않는다. 현재 bark는 물기 명중·컷신에서만 두 전자음으로 재생된다. 개 짖는 WAV는 없다.
- **Chosen (Implementation)**: 짧고 거친 성대음과 숨소리가 섞인 게임용 ‘멍!’ 한 번을 원본 합성 WAV로 제작한다. 44100Hz mono PCM16, 약 0.4초. 단순한 두 음 높이 비프음은 대체한다. 성공한 bark `skill-used`에만 한 번 재생하고 쿨타임·잠금 거절에는 재생하지 않는다. 기존 Tone 컨텍스트·binary preload·pause/shutdown 소스 정리를 재사용한다. 오디오 파일 존재/파형 검사와 실제 출력 확인을 분리한다.

## D08. 일반 장애물 구간의 사용 범위
- **Chosen (User)**: 보스전뿐 아니라 장애물 구간에서도 스킬을 사용할 수 있게 한다.
- **Chosen (Implementation)**: 이번 요청의 스킬은 현재 해금 가능한 짖기를 기준으로 한다. 월드 1 클리어로 해금한 뒤 월드 1 재도전과 월드 2 장애물 구간에서 이미지·소리·공통 10초 쿨타임/HUD가 동작한다. 미해금 첫 플레이의 해금 순서는 유지한다.
- **Chosen (Codebase)**: StageScene 입력에는 이미 boss 전용 제한이 없다. 이미지·소리가 없어서 사용을 알아보기 어렵다. 일반 적 경직·장애물 파괴는 현재 짖기 효과에 구현되어 있지 않다. 이번 범위는 사용 피드백을 완성하고 기존 삼색이 경직을 유지한다. 후속 스킬이나 일반 적의 새 전투 효과는 이번 추가 요청만으로 만들지 않는다.
