# Decisions: 코기 물기 전신 스프라이트

- Date: 2026-10-28
- Status: Confirmed from user correction and existing appearance contract

## D01. 이중 얼굴의 원인과 교체 방향

- **Chosen**: 얼굴만 그린 `corgi-bite.png`와 기본 코기를 동시에 그리는 방식을 폐기한다. 112×128 프레임 네 개가 모두 머리·몸·발·꼬리를 포함하는 물기 스프라이트 시트로 교체하고, 320ms 동안 `Player` 본체의 텍스처로 재생한다. [사용자 요청 + `PlayerAnimator` 확인]
- **Rationale**: 현행 `biteImage`는 플레이어보다 높은 depth의 별도 Sprite이고, 기본 얼굴이 그 아래에 남아 두 겹으로 보인다. 본체 하나의 텍스처를 바꾸면 겹침이 구조적으로 사라진다.

## D02. 좌표·스킬 계약

- **Chosen (사용자 정정 반영)**: `corgi-bite` manifest 키와 448×128 PNG/112×128 네 프레임/80ms 간격/320ms 표시를 유지한다. 기존 코기의 색·비율·안광 없는 눈을 기준으로 0=웅크려 힘 모으기, 1=몸통과 앞다리를 뻗어 돌진, 2=턱을 닫으며 앞발 착지, 3=몸 전체를 낮춰 복귀하는 **전신 자세를 새로 그린다**. 달리기 시트의 몸통·발 픽셀을 복사하거나 동일하게 유지하지 않는다. 좌우는 현재 `flipX`를 사용하고 `Player`의 72×40 Arcade body, 물기 명중·피해 2·6초 쿨타임·E 입력은 바꾸지 않는다. [사용자 정정 2026-10-28]

## D03. 의상과 장신구

- **Chosen**: 물기 자세에서도 착용 의상을 유지한다. 기본 코기는 `corgi-bite`를 사용한다. 상점 의상 5종은 각각 전신 물기 4프레임 시트를 만들고, 직접 그린 의상은 별도 흰색 물기 템플릿에 기존 56×32 셀 색을 입힌다. 별도 장신구·장비 레이어는 계속 표시한다. [사용자 확인 2026-10-28]
- **Rationale**: 의상은 `Player` 본체 텍스처에 합쳐져 있고 바나나 후드·핫도그 의상은 얼굴 주변까지 그려져 있다. 기본 물기 시트로 대체하거나 기본/의상 run 이미지의 변경 픽셀만 합치면 의상 일부가 지워지거나 옛 얼굴이 남을 수 있다. 의상별 전신 시트가 한 장의 얼굴과 옷을 함께 표현한다.

## D04. 중단과 복귀

- **Chosen**: 짖기, 사망, 재시도, 컷신, 장면 종료, 물기 320ms 완료 시 현재 착용 상태의 달리기 텍스처로 복원한다. 물기 중 의상 변경이 발생해도 제거된 동적 텍스처를 참조하지 않는다. 텍스처 생성에 실패하면 게임 플레이와 피해 판정은 유지하고 물기 그림만 건너뛴다.

## D05. 전용 물기 효과음

- **Chosen**: 전신 이미지와 함께 물기 효과음도 수정한다. `bite-hit`가 짖기 음원을 재사용하는 연결을 전용 `bite` WAV 재생으로 바꾼다. 짧은 타격·씹기 소리를 로컬에서 직접 생성해 필수 피드백 에셋으로 등록하고, 기존 일시정지·오디오 잠금·장면 종료 처리를 재사용한다. [사용자 확인 2026-10-28]
- **Rationale**: 현재 `StageScene`과 `PrototypeScene`은 물기 스킬 사용이 승인되면 `bite-hit`를 한 번 내지만, `AudioManager`는 이를 `bark`에 연결한다. 이벤트 발행 지점을 그대로 두고 오디오 매핑만 바꾸면 전투·쿨타임을 건드리지 않으면서 두 스킬의 소리가 구별된다.

## Correction to the original plan

- 최초 T01/T02 청사진의 "run 몸통·발 픽셀 유지" 조건은 사용자가 원한 물기 전신 동작과 충돌했다. 해당 조건을 폐기하고 일곱 시트 모두 몸통·다리·의상이 물기 네 자세에 맞춰 달라지는 것으로 바로잡는다.
- 검증 기준도 run과의 픽셀 동일성 대신 몸통 실루엣 변화, 두 번째 프레임의 앞다리 전진, 네 프레임의 서로 다른 몸 자세, 검은 눈의 안광 부재로 교체한다.
