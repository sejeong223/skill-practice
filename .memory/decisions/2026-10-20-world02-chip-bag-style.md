# 결정: 월드 2 포카칩 봉지 참고 구도

- 사용자 참고 이미지의 큰 구도(흰색 밀봉 윗부분, 빨간 로고, 파란 하단, 노란 감자칩)를 반영한다.
- 실사 질감·작은 상품 정보·정확한 포장 복제는 제거하고, 월드 1 소품의 굵은 보라색 외곽선과 단순한 픽셀 면을 따른다.
- 사용자가 이전에 요청한 정확한 `포카칩` 글자를 유지한다. 생성 원화에는 글자를 넣지 않고 조합 스크립트에서 합성한다.
- 서 있는 봉지 실루엣을 살려 80×84px로 교체한다. 스프링 기구와 접촉 판정은 유지하며 기본 점프로 넘을 수 있어야 한다.
- 진행 중인 굿보이 마켓 P02-T01 포인터는 이 수정 후 복원한다.
