# 실제 개 짖음과 3초 쿨타임 결정

- 기존 합성 짖음이 실제 개 소리로 들리지 않는다는 사용자 피드백을 반영한다.
- 짖기 성공 시 실제 개가 한 번 짖은 녹음으로 교체한다. Wikimedia Commons의 공개 도메인 `George vuf 1996.ogg`를 출처로 사용하고, 게임 호환성을 위해 PCM WAV로 변환한다.
- 기존 Tone/Web Audio 재생 경로를 유지한다. HTML5 Audio API는 재생 수단이며 음색 문제의 원인은 음원 자체다.
- 짖기 쿨타임은 모든 게임 구간에서 3초다. 세 번째 *성공한* 짖기마다 발생하는 경고와 화면 흔들림은 유지한다.
- 기존 작업 트리의 다른 메모 수정은 이번 작업에 포함하지 않는다.

원본: https://commons.wikimedia.org/wiki/File:George_vuf_1996.ogg
