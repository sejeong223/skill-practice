# Decisions: 월드 3 공사장 장애물 2종 추가

- Date: 2026-10-27
- Status: Confirmed
- 후속 변경: 케이블 드럼을 옆으로 누운 금속 드럼통(`drum-barrel`)으로 교체한다. 배치 수·접근 거리·이동 속도·이동 거리는 유지하고, 새 그림에 맞춰 충돌 영역 높이를 조정한다. [사용자 후속 요청]

## D01. 추가할 장애물 종류
- **Chosen**: 금속 드럼통(`drum-barrel`)과 손수레(`wheelbarrow`)를 월드 3 일반 스테이지의 새 픽셀 아트 장애물로 사용한다. [사용자 후속 요청]
- **Rationale**: 둥근 금속 드럼통과 바퀴·손잡이가 있는 손수레는 기존 안전 콘, 벽돌 더미, 시멘트 포대, 철제 파이프와 실루엣이 다르다. 그림은 기존 월드 3의 오후 3~4시 공사장 색감과 픽셀 크기에 맞춘다.

## D02. 행동 방식
- **Chosen**: 손수레는 제자리에 놓인 장애물이다. 드럼통은 진행 방향 앞에 보이다가 코기가 왼쪽에서 240px 이내로 접근하면 코기 쪽(왼쪽)으로 굴러오기 시작한다. [사용자 선택 및 후속 외형 변경]
- **Rationale**: 기존 4종은 고정되어 있다. 드럼은 가까이 가면 움직이는 새 패턴을 만들되, 처음부터 화면 밖에서 달려오지 않도록 한다. [기존 동작은 코드 확인]

## D03. 드럼 이동 범위와 속도
- **Chosen**: 드럼은 초당 160px로 최대 약 160px를 굴러온 뒤 멈춘다. 한 번 멈추면 그 시도에서는 그대로 있고, 사망 후 재시작하면 원래 자리와 대기 상태로 돌아간다. [사용자 선택]
- **Rationale**: 코기의 기본 달리기 속도는 초당 240px이다. 짧게 굴러오는 패턴으로 반응할 시간을 주고, 이미 구현된 꺼지는 바닥을 드럼이 가로지르지 않게 한다. [달리기 속도와 바닥 위치는 코드 확인]

## D04. 충돌 결과
- **Chosen**: 코기가 드럼이나 손수레에 닿으면 기존 공사장 장애물처럼 즉시 사망하고 현재 체크포인트/시작점에서 재시작한다. [사용자 선택]
- **Rationale**: 월드 3 장애물 시스템은 접촉 시 `death-requested`를 내보내고 재시작 시 접촉 상태를 초기화한다. 같은 규칙을 쓰면 위험물을 알아보기 쉽다. [기존 이벤트 경로는 코드 확인]

## D05. 전체 배치 수
- **Chosen**: 새 종류를 기존 장애물 자리에서 교체한다. 일반 스테이지마다 장애물 총 8개를 유지하고, 6종을 섞는다. [사용자 선택]
- **Rationale**: 각 스테이지에는 이미 장애물 8개, 숨겨진 꺼지는 바닥 4곳, 간식 코인 15개가 있다. 별도 장애물 자리를 늘리지 않아 과밀 배치와 낙사 구간 중복을 피한다. [현황은 코드 확인]

## D06. 스테이지별 새 종류의 개수
- **Chosen**: 1스테이지는 드럼 1개·손수레 1개, 2스테이지는 드럼 2개·손수레 1개, 3·4스테이지는 각각 드럼 2개·손수레 2개로 한다. 나머지 자리는 기존 4종으로 채운다. [사용자 선택]
- **Rationale**: 스테이지가 진행될수록 굴러오는 패턴을 먼저 늘리고, 뒤 스테이지에서 두 새 종류가 모두 자주 보이게 한다.

## D07. 배치·재시작의 코드 계약
- **Chosen**: 드럼의 160px 이동 구간과 손수레의 실제 그림·충돌 영역이 기존 장애물, 꺼지는 바닥, 코인, 체크포인트, 출구와 겹치지 않도록 기존 8개 슬롯 안에서 종류를 배정한다. 필요한 코인 좌표만 조정하고 코인 15개의 ID와 수집 보상은 유지한다. 보스 스테이지에는 이 일반 스테이지 장애물을 추가하지 않는다. [기존 구조에서 확정]
- **Rationale**: `getWorld03Obstacles`가 4개 일반 스테이지에만 8개의 고정 좌표를 제공하고, `getWorld03CollapseZones`가 별도의 4개 구멍을 제공한다. 화면 그림과 충돌 판정을 맞춰야 하며, 재시작 시 움직이는 드럼의 그림·판정·접촉 대기를 함께 복원해야 한다.
