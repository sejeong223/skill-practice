# Decisions: 월드 2 반복 비둘기 배설

- Date: 2026-10-21 (Asia/Seoul)
- Status: 사용자 요청 및 기존 코드 확인으로 확정

## D01. 요청 범위

- **사용자 선택**: 월드 2 비둘기는 한 번만 똥을 떨어뜨리지 않고 비행 중 여러 번 떨어뜨린다. 비둘기는 2초 간격으로 계속 나타난다.
- **기존 구현에서 확정**: 현재 기믹이 연결된 `world-02-stage-1`의 세 구간에 적용한다. 첫 구간에 들어서면 즉시 첫 새가 나타나고, 플레이 중에는 2,000ms마다 현재 구간에 새 비행을 추가한다. 세 구간의 기존 예고·충돌·체크포인트 원칙은 유지한다.

## D02. 비행과 낙하 패턴

- **코드를 읽고 자동 확정**: 한 마리가 오른쪽에서 왼쪽으로 날며 해당 구간 중심의 `+44`, `0`, `-44`px에 똥을 세 번 떨어뜨린다. 현재 비행 속도 160px/s에서 낙하 간격은 약 0.28초다. 각 위치에 개별 예고 그림자를 약 0.5초 먼저 표시하고, 낙하 중 접촉만 즉시 사망으로 처리한다.
- **이유**: 기존 세 중심점은 장애물 사이를 피해서 정해졌다. 44px씩 분산하면 낙하가 구분되면서 양옆 장애물과의 회피 여유를 유지한다. 첫 새와 다음 새의 시작 간격을 2초로 재므로 비행 중인 새가 겹칠 수 있다.

## D03. 상태 수명

- 스폰 타이머는 게임 플레이 시간에 따라 진행하므로 일시정지·상점에서 멈춘다. 죽음·체크포인트 재시작·장면 종료 시 비둘기와 모든 낙하물·콜라이더·경고·자국을 정리한다. 체크포인트 뒤에서 재개하면 뒤쪽 두 구간은 재생성하지 않는다.
- 새 디자인, 저장 스키마, 월드 2 후속 스테이지와 월드 1 비둘기는 변경하지 않는다.
