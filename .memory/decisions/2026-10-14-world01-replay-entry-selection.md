# Decisions: 월드 1 재도전 시작 지점 선택

- Date: 2026-10-14
- Status: Confirmed

## D01. 월드 1 하위 목록

- **Chosen (User)**: 월드 선택 창에서 월드 1을 누르면 시작 지점을 세로 목록으로 보여준다. 순서는 `처음부터`, 실제 체크포인트를 순서대로, 마지막 `보스전`이다.
- **Chosen (Codebase)**: 월드 1의 실제 깃발은 2스테이지 `world-01-stage-2-checkpoint`와 4스테이지 `world-01-stage-4-checkpoint` 두 개다. 따라서 세로 목록은 `처음부터`, `체크포인트 1 · 2스테이지`, `체크포인트 2 · 4스테이지`, `보스전`의 네 항목이다. 월드 2 버튼은 현재처럼 1스테이지로 이동한다.
- **Rationale**: 맵 정의 `world01Checkpoint()`은 1·3스테이지에 깃발을 생성하지 않는다. 없는 지점을 선택지에 넣으면 실제 플레이 위치와 다르게 작동한다.

## D02. 체크포인트 진입

- **Chosen (Inferred implementation)**: 체크포인트 항목은 해당 스테이지의 시작점이 아닌 실제 깃발 위치에서 시작한다. 선택 시 예전 월드 1 체크포인트 스냅샷을 지우고 선택한 깃발을 새 복귀 지점으로 저장한다. `처음부터`는 체크포인트를 비운다.
- **Rationale**: `StageScene.create`는 `resumeCheckpointId`를 받으면 `restoreCheckpoint()`로 깃발 위치를 복원한다. 저장 스냅샷이 없더라도 해당 깃발을 조용히 활성화할 수 있다.

## D03. 보스전 패배와 복귀

- **Chosen (User)**: 목록에서 `보스전`을 직접 선택한 뒤 패배하면 보스전에서 바로 재도전한다.
- **Chosen (Inferred implementation)**: 보스전을 직접 선택했다는 저장 플래그를 추가하고, 패배 시 보스 Scene을 새로 시작해 보스 체력·패턴도 초기화한다. 새로고침해도 선택한 보스전으로 돌아온다. `처음부터`나 체크포인트를 선택하면 이 플래그를 해제한다.
- **Rationale**: 현재 보스 패배 복귀는 월드 1의 이전 깃발을 목표로 한다. 현재 Scene에서 플레이어만 리셋하면 보스 상태가 남을 수 있으므로 Scene 전체 재시작이 필요하다.

## D04. 기존 진행 보존

- **Chosen (Codebase)**: 월드 선택은 월드 1 보스 클리어 후에만 열고 네 시작 지점을 모두 제공한다. 선택지 이동은 기존 클리어 기록·스킬·코인·장비·사망 통계를 초기화하지 않는다. 보스 재클리어 성공 시 보스 직접 재도전 상태를 종료해 월드 2로 이어진다.
- **Rationale**: 이전 기능은 `selectedWorldId`를 저장하고 보스 클리어를 월드 선택 해금 조건으로 사용한다. 이를 재사용하면 이전 저장과 월드 2 이동이 유지된다.

## D05. 별도 문제

- **Chosen (Codebase)**: 보스 재클리어 시 이미 배운 짖기 해금 안내가 다시 나오는 기존 동작은 이번 시작 지점 선택 요구와 분리한다.
- **Rationale**: 해금 안내 Scene의 반복 표시를 바꾸려면 보스 승리 보상 연출 정책을 별도로 결정해야 한다.
