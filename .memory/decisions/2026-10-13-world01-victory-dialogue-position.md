# 결정: 삼색이 방향·승리 대화와 클리어 표시

- 사용자 요청: 보스전 종료 후 코기를 시작 위치로 이동시키지 않고, 전투가 끝난 현재 위치에서 삼색이와 대화한다. 이번 요청은 계획서 수정이며 구현은 하지 않는다.
- 코드 확인: `StageScene.handleCalicoDefeat()`에는 시작 위치로 이동시키는 호출이 없다. `CutsceneDirector.play()`는 `lockControl("cutscene")`만 적용하고, `StageScene.update()`는 cutscene 상태에서 조작 업데이트를 건너뛴다. 이미 남아 있는 속도와 Arcade 물리는 계속되어 대화 중 이동할 수 있다.
- 마지막 공격으로 승리가 확정되면 첫 대사 이벤트 전에 코기만 물리 이동을 멈추고 대기 자세로 바꾼다. 당시 월드 좌표 x/y와 방향은 유지한다. 시작점·체크포인트·고정 연출 좌표로 이동하지 않는다.
- 점프 중 승리해도 대화 중에는 그 순간의 x/y에 고정한다. 별도의 착지·자동 이동 연출을 추가하지 않는다.
- 화자별 카메라 초점, 줌1, 대사 내용/자동 진행/수동 넘김/재시청 건너뛰기와 짖기 보상·클리어 화면 흐름은 유지한다. 기절 이미지 표시 시점은 아래 추가 요청대로 첫 대사 전으로 앞당긴다. 월드 전체나 씬을 멈추지 않는다.
- 이전 완료 계획의 사망 반복/맵 끝 낙하 수정은 보존한다. 보스 패배 후 깃발 부활과 일반 맵의 자동 전환/진행 저장도 유지한다.
- 추가 요청: 전투 중 삼색이는 코기의 현재 x위치를 따라 좌우 방향을 바꾼다. 코기가 왼쪽이면 왼쪽, 오른쪽이면 오른쪽을 보고, 정확히 같은 x에서는 이전 방향을 유지한다. 쓰러진 뒤에는 마지막 방향을 유지한다.
- 기존 `calico-boss.png`를 확인했다. 96×96 프레임3개이며 원본은 오른쪽을 본다. frame0 대기, frame1 투척, frame2 쓰러짐이다. 새 이미지 제작 없이 frame2를 승리 대화 시작 전부터 표시한다. `stopAttacks()` 재호출이 frame0으로 되돌리지 않게 한다.
- 현재 영문 `[STAGE CLEAR!]`의 정상 표시 경로는 `World01StageClearScene` 하나다. 일반 맵 끝에는 `GameShell`의 `스테이지 클리어를 저장했습니다.` 알림이 여전히 출력된다. 실행 단계에서 실제 DOM과 Phaser 텍스트를 함께 확인하여 일반 맵의 완료 문구를 없앤다. 문구 제거를 위해 `stage-completed` 이벤트나 저장/전환 기능을 삭제하지 않는다.
- `STAGE CLEAR!`는 보스를 쓰러뜨리고 승리 대화가 끝난 뒤, 다음 월드로 넘어가는 전용 화면에서만 표시한다. 4단계→보스전 진입은 일반 맵 전환이므로 표시하지 않는다. 보스 패배/재도전에서도 표시하지 않는다.
- 기존 P01/T01(코기 정지)을 유지하고 T02(삼색이 방향/기절 시점), T03(일반 맵 클리어 문구 제거)을 같은 Phase에 추가한다. 각각 독립적인 관찰 결과와 한국어 커밋으로 검증한다. 이번에도 계획 문서만 수정한다.
