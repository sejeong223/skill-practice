# 결정: 보유 아이템 카탈로그와 착용 해제

## 사용자가 확정한 내용

- 이미 착용한 아이템을 다시 뺄 수 있게 한다. **의상·장신구**에는 빈 슬롯(벗기)을 허용한다.
- **무기·방패는 벗지 않고**, 카탈로그에서 이미 보유한 다른 무기·방패로 교체한다.
- 별도 **카탈로그 메뉴**에는 보유한 아이템만 표시하며, 거기서 다시 장착·착용한다. 상점에 없는 미보유 상품을 보여 주거나 카탈로그에서 구매하지 않는다.

## 현재 코드와 일치시키기 위해 확정한 기준

- 카탈로그 버튼은 현재 상점 버튼과 같은 게임 상단 메뉴에 둔다. 월드 1·2 플레이 중 열고, 열려 있는 동안 물리·타이머·입력과 스테이지 음악을 일시정지하며 닫으면 이어서 진행한다. 상점 출입 종·음악과 주인 대사는 카탈로그에서 재생하지 않는다.
- 의상·장신구를 착용 중일 때는 상점의 해당 보유 상품과 카탈로그 모두에 `벗기`를 제공한다. 벗기 후 소유권은 유지하고 표시 버튼은 `착용`으로 되돌아간다. 무기·방패는 현재 장착 아이템에 `장착 중`을 표시한다.
- 카탈로그는 무기·방패·의상·장신구 네 분류를 사용한다. 각 분류에 보유품만 보여 주고 비어 있으면 안내 문구를 표시한다. 분류 안에서는 카드 목록을 세로로 스크롤하며 `장착`/`착용`/`벗기` 버튼을 누른다.
- 기본 토끼 슬리퍼·뒤집힌 밥그릇 및 예전 저장에 남은 종이관·종이 상자도 `ownedToolIds`에 있으면 표시하고 교체할 수 있게 한다. 현재 상점의 19종 목록에는 이 네 도구가 없으므로 `TOOL_DEFINITIONS`·`getToolPresentation`을 보조 자료로 사용한다. 전용 상점 아이콘이 없는 도구는 이름이 있는 픽셀형 대체 타일을 쓴다.
- 착용 상태는 기존 `ProgressState.equippedOutfitId`·`equippedAccessoryId`의 `null`과 기존 `cosmetic-change-requested` 이벤트로 저장·화면에 반영한다. 무기·방패의 비어 있지 않은 저장 타입과 기본 장비는 유지한다. 소유권·코인·가격·상품 효과와 저장 스키마 버전은 변경하지 않는다.

## 확인한 제약과 범위

- `ShopPanel`은 현재 착용 중이면 버튼을 비활성화하고, `PlayerWearables`·`StageScene`은 이미 외형 ID의 `null`을 처리한다. 따라서 새 벗기 버튼과 `GameShell`의 이벤트 전달을 연결하면 별도 그림이나 코기 전체 교체가 필요 없다.
- `MARKET_PRODUCTS`는 판매 중인 19종만 담는다. 이 목록만 카탈로그에 사용하면 기본·예전 보유 도구가 누락된다. 보유 목록과 `TOOL_DEFINITIONS`을 함께 읽고 미소유·알 수 없는 ID는 표시하지 않는다.
- 상점은 이미 Escape로 닫을 때 일반 일시정지 입력과 중복되지 않도록 `shopPauseGuard`를 사용한다. 새 카탈로그도 같은 종류의 중복 입력 방지와 상점·월드 선택·초기화 창 간 상호 배제가 필요하다.
- 카탈로그는 장착 메뉴다. 새로운 아이템 제작, 판매, 환불, 추가 능력치, 기본 장비의 외형 파츠 제작은 이번 범위에 넣지 않는다.
