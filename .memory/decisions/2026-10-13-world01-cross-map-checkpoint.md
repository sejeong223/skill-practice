# 결정: 월드1 맵 간 체크포인트 유지

- 사용자는 맵 경계를 넘어 죽으면 다음 맵 시작점에서 부활하는 문제의 수정을 요청했고, 원인 설명 뒤 구현을 승인했다. 앞선 현재 맵 한정 정책을 대체한다.
- 월드1의 마지막 실제 깃발(2단계 또는4단계)을 월드 범위로 유지한다. 다음 맵 진입은 복귀 위치를 갱신하지 않는다. 죽으면 그 깃발이 있는 맵으로 돌아가고, 아직 깃발을 밟지 않았다면1단계 시작점으로 돌아간다.
- 보스 패배도 같은 정책을 따른다.4단계 깃발을 밟지 않았다면 그 깃발을 임의 활성화하지 않는다. 기존900ms 패배 연출과 사망1회 집계는 유지한다.
- 저장에 `world01CheckpointStageId`를 추가한다. v2의 호환 가능한 선택 필드로 읽고, 기본값 null이다. 옛 저장에는 실제 깃발을 밟은 정보가 없으므로 맵 클리어로 깃발 활성화를 추정하지 않는다. 코인·스킬·클리어 기록·사망 기록은 보존한다.
- 월드1 미완료 상태의 재접속도 마지막 깃발 또는 월드 시작점으로 복원한다. 보스 승리 후 클리어 화면 및 월드2 이후의 기존 진행은 유지한다.
- 세션 중에는 깃발의 안전한 맵 스냅샷도 씬 밖 Phaser registry에 보관하여, 돌아온 맵의 기믹 상태를 복원한다. 영구 저장은 깃발 식별자만 유지하며 새로고침 시 지형/기믹은 새 맵으로 구성한다. 진행 중 가짜 간식의 반복 사망 방지는 보존한다.
- 일반 맵 완료 이벤트는 클리어 기록/코인 처리를 위해 유지한다. 일반 완료 문구 제거, 맵 끝 바닥, 보스 방향/기절/코기 정지 동작을 되돌리지 않는다. 다른 월드의 사망 정책과 상점/중복 코인 정책은 변경하지 않는다.
