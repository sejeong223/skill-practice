# Decisions: 전설의 무한 육즙 왕갈비뼈 쟁탈전

- Date: 2026-09-19
- Status: Confirmed

## D01. 게임 장르와 플랫폼
- **Chosen**: 데스크톱 브라우저에서 실행되는 2D 횡스크롤 액션 플랫폼 게임
- **Rationale**: Cat Mario류의 극악한 함정, 정밀한 점프, 즉시 재시작 구조를 가장 직접적으로 구현할 수 있다.

## D02. 렌더링 및 기술 구조
- **Chosen**: Next.js/React 외곽 셸 + Phaser 게임 플레이 레이어 + Phaser Arcade Physics
- **Rationale**: Phaser가 캐릭터·충돌·함정·스테이지를 담당하고, React가 상점·캐릭터 상태 창·키 설정·컷신·엔딩 UI를 담당한다. Arcade Physics는 2D 플랫폼 액션의 충돌을 가볍고 예측 가능하게 통제하기 쉽다.

## D03. 화면 규격과 아트 스타일
- **Chosen**: 1280×720 기준 16:9 고정 플레이 영역, 작은 화면에서는 비율 유지 축소
- **Chosen**: 밝고 선명한 2D 카툰에 살짝 픽셀 아트 감성을 섞은 게임 비주얼
- **Chosen**: 생성형 Image Generator로 제작한 일관된 PNG/SVG 에셋을 주력으로 사용하고, Phaser Graphics는 파티클·충돌 표시·간단한 효과에 사용한다.
- **Rationale**: 유쾌한 분위기와 실제 게임 같은 캐릭터·배경 품질을 함께 확보한다. 픽셀풍 필터와 고정 팔레트·실루엣 규칙으로 생성 에셋의 일관성을 유지한다.

## D04. 입력과 조작 설정
- **Chosen**: 키보드만 지원. 이동은 방향키/WASD, 점프는 Space.
- **Default bindings**: J=공격 슬롯/물기 연계, K=돌진, L=짖기
- **Chosen**: 설정 메뉴에서 사용자가 원하는 키로 재배치 가능
- **Rationale**: 데스크톱 키보드 조작을 단순하게 유지하면서 사용자별 키 선호를 허용한다.

## D05. 캠페인 규모와 진행 구조
- **Chosen**: 5개 월드 × 일반 스테이지 4개 + 보스전 1개 = 총 25개 스테이지
- **Chosen**: 월드와 스테이지를 선형으로 진행하며, 캠페인 중 이전 스테이지로 돌아갈 수 없다.
- **Chosen**: 5월드의 보스가 전체 고양이 패거리의 우두머리이자 최종 보스다.
- **Rationale**: 장편 캠페인의 규모를 확보하면서도 최종 보스를 별도의 26번째 스테이지로 늘리지 않는다.

## D06. 월드 및 장소명 규칙
- **Chosen**: 장소명은 짧고 직관적인 지역명에 괄호 속 설명을 붙이는 방식
- **Examples**: `무법지대 뒷골목`, `냥아치 연합 아지트 (버려진 고물상)`, `들썩들썩 놀이터`, `무한 육즙 공장`, `고양이 왕국 왕궁`
- **Rationale**: 과장된 문장형 제목 대신 귀엽고 유쾌하지만 알아보기 쉬운 지역명을 사용한다.

## D07. 핵심 스토리와 주인공
- **Chosen**: 주인이 강아지의 생일을 맞아 동네 반려견들이 찬양하는 `[전설의 무한 육즙 왕갈비뼈]`를 사 온다.
- **Chosen**: 주인이 사진을 찍기 위해 강아지에게 `기다려`를 명령하고 휴대폰을 가지러 간 사이, 길고양이 냥아치가 왕갈비뼈를 훔친다.
- **Chosen**: 주인은 도입부와 엔딩에만 등장한다.
- **Chosen**: 주인공은 코기이며, 시작 시 플레이어가 이름을 입력한다. 기본 이름은 `코기`다.
- **Chosen**: 강아지는 말을 하지 않고 멍멍, 끼잉, 으르렁거림과 표정·행동으로 감정을 표현한다.

## D08. 왕갈비뼈 설정
- **Chosen**: 365일 내내 씹어도 갓 구운 투뿔 한우급 육즙이 마르지 않는 궁극의 간식
- **Legendary effects**:
  - 슬개골이 아다만티움급으로 단단해진다.
  - 기분이 좋을 때 흔드는 꼬리 모터 출력이 300% 상승한다.
  - 꼬리로 헬리콥터처럼 하늘을 날 수 있다.
- **Chosen**: 고양이 패거리는 왕갈비뼈를 독점해 고양이 왕국을 세우려 한다.
- **Chosen**: 최종 보스전에서 왕갈비뼈는 사용되지 않고, 시각적으로 보이는 탈환 대상일 뿐이다.

## D09. 최종 엔딩
- **Chosen**: 강아지가 모든 스테이지를 돌파해 왕갈비뼈를 입에 물고 집으로 돌아온다.
- **Chosen sequence**:
  1. 주인이 잘 기다렸다고 칭찬하며 강아지의 머리를 쓰다듬는다.
  2. 주인이 코기의 입에서 왕갈비뼈를 빼낸다.
  3. 강아지가 이제 먹을 수 있을 것이라는 기대의 눈빛을 보낸다.
  4. 주인이 해맑게 웃으며 열린 베란다 창문 밖으로 왕갈비뼈를 던진다.
  5. 주인이 `자, (강아지 이름)아!! 물어와!!!!`라고 외친다.
  6. 강아지가 `.......멍?` 하고 당황한 뒤 다시 창밖으로 뛰어든다.
  7. 하늘로 날아가는 강아지를 클로즈업하고 `[ TO BE CONTINUED...? ]`를 표시한다.
  8. 엔딩 크레딧 중에도 강아지가 갈비뼈를 향해 달려가는 모습을 보여주고 완전히 종료한다.

## D10. 카메라와 레벨 진행
- **Chosen**: 강아지를 따라가는 부드러운 횡스크롤 카메라
- **Chosen**: 화면 밖에서 갑자기 나타나는 함정과 적을 허용한다.
- **Rationale**: 정상적인 시야 확보와 의도적인 억까를 동시에 사용할 수 있다.

## D11. 난이도와 사망 규칙
- **Chosen**: 별도 쉬움·보통·연습 모드 없이 하나의 기본 억까 난이도만 제공한다.
- **Chosen**: 목숨 제한 없음, 사망 후 즉시 재시작
- **Chosen**: 누적 사망 횟수를 기록하고 캐릭터 상태 창에서 전체·월드별·스테이지별로 확인한다.
- **Chosen**: 사망 연출은 피와 고어 없이 납작해짐, 털 폭발, 뼈 실루엣 같은 만화식 블랙코미디로 처리한다.

## D12. 체크포인트와 함정 패턴
- **Chosen**: 긴 스테이지당 체크포인트 1개
- **Chosen**: 체크포인트는 일반 게임보다 현저히 드물게 배치하며, 체크포인트 이후에도 긴 억까 구간을 유지한다.
- **Chosen**: 대부분의 함정은 고정 패턴이고, 일부 함정과 고양이 행동만 재시도마다 랜덤하게 변한다.
- **Chosen**: 화면 밖 공격, 무표시 즉사, 강제 낚시, 첫 시도에서 사실상 피하기 어려운 함정을 허용한다.

## D13. 적과 보스
- **Chosen**: 전투와 함정의 하이브리드. 고양이는 물리칠 수 있지만 주된 위협은 환경 함정과 낚시 패턴이다.
- **Chosen**: 월드당 고양이 간부 보스 1명. 5월드의 보스는 전체 고양이 패거리의 우두머리다.
- **Chosen**: 고양이 이름은 과한 말장난을 피하고, 기억하기 쉬운 이름과 행동 중심의 개성을 사용한다.

## D14. 스킬 성장
- **Chosen**: 간부 보스 처치 직후 다음 월드에서 사용할 핵심 스킬 1개를 해금한다.
- **Unlock order**: 짖기 → 물기 → 돌진 → 이단 점프 → 꼬리 회전
- **Chosen**: 모든 스킬은 개별 쿨다운을 사용한다.
- **Chosen**: 꼬리 회전은 왕갈비뼈의 완전한 헬리콥터 비행이 아니라, 그 전 단계인 공중 제어 능력으로 구현한다.

## D15. 기본 공격 도구와 물기 스킬 연계
- **Chosen**: 기본 공격 도구는 `[주인님의 애착 토끼 슬리퍼]`다.
- **Attack loop**:
  - J 입력 시 강아지가 슬리퍼를 물고 휘둘러 적을 공격한다.
  - 3연타 시 슬리퍼에서 솜먼지가 터지고 강아지가 `에취!` 하며 뒤로 3m 밀려난다.
  - 물기 스킬 해금 후에는 슬리퍼를 놓은 직후 J를 다시 입력해 악당을 직접 앙 물 수 있다.
- **Rationale**: 강아지가 슬리퍼를 손으로 잡을 수 없다는 설정을 반영하고, 도구와 스킬이 하나의 코믹한 공격 콤보를 이룬다.

## D16. 상점 도구 구조
- **Chosen**: 공격 슬롯 1개와 방어 슬롯 1개를 장착한다.
- **Chosen**: 모든 도구는 상점 목록에 보이지만 가격을 크게 차등화한다. 후반 도구는 초반에 안정적으로 구매하기 어렵다.
- **Chosen**: 상점은 각 스테이지 시작 전 안전 구역에만 존재하고, 스테이지 내부에는 없다.
- **Chosen**: 캐릭터 상태 창에서만 장비를 교체한다. 살아 있고 컷신·사망 연출 중이 아닐 때만 교체할 수 있으며, 교체해도 기존 스킬 쿨다운은 유지한다.
- **Chosen**: 공격 도구는 영구 보조 효과, 방어 도구는 제한 횟수형 보호 효과다.

## D17. 기본 방어 도구와 억까 부작용
- **Chosen**: 기본 방어 도구는 `[뒤집어진 강아지 밥그릇]`이다.
- **Effect**: 약한 공격을 최대 3회 막고, 3회 사용 후 해당 스테이지에서 망가진다.
- **Hidden drawback**: 방어할 때마다 큰 `챙!` 소리가 난다.
- **Consequence**: 소리를 들은 동네 유기견 NPC들이 몰려와 적을 같이 물어뜯지만, 길목을 꽉 막아 플레이어의 도망·점프 공간을 없앤다.
- **Global rule**: 모든 공격·방어 도구에는 강력한 장점과 하나 이상의 억까 부작용을 둔다.
- **Discovery rule**: 구매 설명에는 장점만 표시하고 부작용은 첫 발동 전까지 숨긴다. 실제로 발동한 후 캐릭터 상태 창의 도구 기록에 공개한다.

## D18. 간식 코인 경제
- **Chosen**: 코인은 안전 금고 코인과 현재 스테이지 코인으로 나눈다.
- **Current-stage coins**: 해당 스테이지에서 새로 모은 코인. 사망하면 100% 사라진다.
- **Banked coins**: 스테이지를 클리어하면 남은 코인이 안전 금고로 이월된다. 다음 스테이지에서 사망해도 잃지 않는다.
- **Chosen**: 스테이지 간 후퇴가 불가능하므로 재플레이 파밍은 제공하지 않는다.

## D19. 저장
- **Chosen**: 브라우저 자동 저장
- **Persisted**: 클리어한 스테이지, 해금 스킬, 영구 장비, 안전 금고 코인, 수집품, 사망 통계, 키 설정
- **Not persisted**: 진행 중인 스테이지의 위치와 현재 스테이지 코인

## D20. 수집품과 컷신
- **Chosen**: 스테이지마다 숨겨진 선택형 수집품을 배치한다. 예: 생일 초, 간식 봉투, 고양이 문서.
- **Chosen**: 수집하지 않아도 캠페인은 진행된다.
- **Chosen**: 월드 시작, 간부 보스 처치 후, 주요 발견 지점에 짧은 선형 컷신과 대화를 넣는다.
- **Chosen**: 첫 재생 컷신은 자동 재생하고, 이미 본 컷신은 스킵할 수 있다.

## D21. 사운드
- **Chosen**: 귀여운 발소리·멍멍·코믹 효과음과 점점 불안해지는 음악의 대비
- **Rationale**: 밝은 카툰 외형과 잔혹한 억까 상황의 블랙코미디 대비를 강화한다.

## D22. 생성형 에셋 제작 방식
- **Chosen**: 사용자가 직접 캐릭터를 그리지 않고, 생성형 이미지 도구로 코기·고양이·도구·배경의 기준 디자인과 변형 에셋을 제작한다.
- **Chosen**: 코기 기준 이미지와 스타일 가이드를 먼저 확정한 뒤, 포즈·표정·애니메이션 프레임·스테이지 에셋을 참조 기반으로 확장한다.
- **Rationale**: 디자인 역량을 사용자에게 요구하지 않으면서도, 25개 스테이지 전체의 시각적 일관성을 유지한다. 생성 결과는 투명 배경·프레임 정렬·충돌 영역을 정리한 뒤 Phaser 스프라이트/아틀라스로 사용한다.
