# Plan: 월드 1 쉬운 통과 개편

> 상태: **superseded**. 이 문서의 평평한 2·4단계, 스테이지마다 체크포인트, 턱시도 2회 공격 보스는 실행하지 않는다. 최신 실행 계획은 [월드 1 낮 경로와 삼색이 보스](./2026-09-29-world01-daylight-calico.md)를 따른다. 가짜 간식 코인 3종 각 2개 결정만 새 계획으로 이어진다.

## Goal
월드 1 일반 스테이지 4개를 처음부터 보이는 정적 장애물과 선택적으로 피하는 가짜 간식 코인으로 완주할 수 있게 한다. 보스 스테이지는 쉬운 2회 공격 전투와 안전한 출구로 마무리한다. 기존 66개 돌발 기믹은 30개로 줄인다.

## Decisions
- [2026-09-29 월드 1 쉬운 통과 개편](../decisions/2026-09-29-world01-easy-pass.md)
- 사용자 확인: 보스 스테이지까지 난이도 하향 범위에 포함하고, 새 쉬운 보스전을 만든다.

## Execution Order
1. T01에서 정적 장애물과 갈매기 그림의 공통 런타임을 추가한다. 기존 맵은 이 Task에서 유지한다.
2. T02에서 4개 일반 스테이지의 카탈로그와 맵을 함께 교체하고 검증 기준을 새 배치에 맞춘다.
3. T03에서 보스 스테이지의 대체 바닥과 턱시도 고양이 2회 공격 전투를 구현한다.
4. T04에서 일반 4개→보스 진행, 클리어·해금 저장, 맵/보스 자동 검증과 수동 플레이테스트 결과를 기록한다.

## Completion Gate
- [ ] 4개 일반 스테이지는 좌우 이동·점프만으로, 보스는 기본 `J` 공격 2회로 끝낼 수 있다.
- [ ] 보스는 정지 상태이며 공격·시간 제한·돌발 소환이 없고, 승리 전에는 출구가 클리어되지 않는다.
- [ ] 처음에는 안 보이다가 출현하거나 입력·타이머로 생성되는 월드 1 장애물이 0개다.
- [ ] 가짜 간식 코인 3종이 각각 2개 남고, 강제 수집 없이 지나갈 수 있다.
- [ ] 정적 장애물·가짜 코인 30개, 체크포인트 1개/일반 스테이지, 안전한 시작/끝 구간이 검사된다.
- [ ] 각 스테이지 클리어와 보스의 짖기 해금이 저장되고, 다시 시작하면 첫 미완료 스테이지에서 이어진다.
- [ ] `npm.cmd run world01:maps:check`, `npm.cmd run lint`, `npm.cmd run build`가 통과하고 [새 플레이테스트 표](../test-plans/2026-09-29-world01-easy-pass.md)가 채워진다.
- [ ] 사용자에게 새 월드 1 경로를 보여주고 확인받기 전에는 월드 2 계획 포인터를 활성화하지 않는다.
