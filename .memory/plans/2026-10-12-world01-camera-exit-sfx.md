# Plan: 대사 카메라와 출구·체크포인트·효과음 수정

## Goal

축소로 드러나는 맵 바깥을 없애고 화자별 카메라를 사용한다. 일반 맵은 끝으로 걸어나가면 전환하고 부활은 밟은 깃발 위치로 한다. 신규 제작한 간식·체크포인트 효과음이 실제 플레이에서 출력된다.

- [결정](../decisions/2026-10-12-world01-camera-exit-sfx.md)
- 사용자 수정 요청으로 계획 완료 후 실행까지 연속 진행한다.

## Scope

T01은 카메라만, T02는 출구/체크포인트 동작, T03은 효과음과 최종 회귀를 맡는다. 같은 StageScene을 순차 수정한다. 맵 유사성은 데이터 조사 결과를 보고하며 지형이나 이미지를 새로 교체하지 않는다. 기존 무관한 메모리 변경은 보존한다.

후속 T04는 맵 끝에서 다음 맵으로 넘어가기 전 낙하하는 현상을 수정한다. 일반 맵의 화면 밖 이동 구간에 지면과 같은 높이의 숨겨진 충돌 바닥을 연장한다.
