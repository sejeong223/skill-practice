# Plan: 보유 아이템 카탈로그와 착용 해제

## Goal

월드 1·2에서 보유한 네 분류의 아이템을 별도 카탈로그에서 다시 착용하게 하고, 의상·장신구는 상점과 카탈로그에서 벗겨 코기 외형과 저장 상태를 즉시 바꾼다.

## Confirmed Decisions

[결정 문서](../decisions/2026-10-21-owned-item-catalog.md)를 따른다. 무기·방패는 보유품 사이에서 교체만 하고, 카탈로그에는 소유한 품목만 표시한다.

## Task Order

1. **T01 보유품 모델과 외형 벗기** — 기존 저장 소유권에서 상점 판매품·기본 도구·예전 도구를 안전하게 모으고, 상점에서 착용 중인 의상·장신구를 벗겨 저장·코기 파츠를 갱신한다.
2. **T02 카탈로그 메뉴와 통합 검증** — 상단 버튼·보유품 목록·교체/벗기 동작·게임 일시정지를 연결하고 데스크톱·모바일, 새로고침, 실제 전투를 확인한다.

## Task Boundary Rationale

- T01은 기존 상점에서 바로 확인 가능한 완결된 벗기 흐름과 보유품 선택 모델을 만든다. T02는 그 모델을 새 메뉴에 연결하므로 이미 검증한 소유권·저장 규칙을 다시 만들지 않는다.
- 상점의 구매·전용 음악, 기존 상태 창의 도구 변경, 월드 선택 동작을 유지한다. 카탈로그는 구매 기능이 없고 출입음도 재생하지 않는다.

## Regression Gates

- `ProgressState.equippedAttackToolId`·`equippedDefenseToolId`는 필수 문자열이며, 기본 토끼 슬리퍼·밥그릇을 포함한 소유 장비 중 하나여야 한다. 빈 슬롯을 지원하려고 저장 타입이나 전투 기본값을 바꾸지 않는다.
- `ShopPanel`의 착용 중 버튼은 **의상·장신구에만** `벗기`로 바뀐다. 구매 완료 후 즉시 착용, 무기·방패의 장착 중 표시는 그대로다.
- 보유 카탈로그는 기본·예전 도구를 누락하거나, 미보유 상품을 우회 장착시키면 안 된다. 벗기와 재착용을 새로고침 뒤에도 유지한다.
- 일시정지·상점·카탈로그·월드 선택·초기화 창은 겹쳐 열지 않는다. Escape 한 번으로 카탈로그만 닫히고 게임이 다시 멈추지 않게 한다.

## Validation Gate

각 Task의 명시된 검사에 더해 `npm.cmd run lint`, `npm.cmd run build`, `node node_modules/typescript/bin/tsc --noEmit`을 통과시킨다. T02에서 Chrome으로 구매→착용→벗기→재착용→새로고침과 보스전 도구 교체, 모바일 메뉴 배치를 확인한다.
