# Plan: 코기 맞춤 의상·픽셀 그림판·월드 2~5 보스

## Goal

- 기존 코기 스프라이트에 의상 5종과 장신구 5종을 프레임별로 꼭 맞게 입힌다. 생일 고깔모자는 두 귀를 덮는다.
- 무료 흰 옷을 픽셀 그림판에서 그려 최대 3벌 저장하고 카탈로그에서 장착·해제한다. 상점·카탈로그·그림판은 월드 1~5 플레이 중 열며 게임을 일시정지한다.
- 월드 3 전체를 공사장으로 바꾸고 월드 4·5 명칭과 인트로를 확정된 설정에 맞춘다.
- 월드 2 치즈 태비, 3 고등어, 4 턱시도, 5 메인쿤의 고유 전투를 구현한다. 체력 15/20/25/40, 기본 공격 주기 3.0/2.6/2.2/1.5초, 무기 피해 1/2/3을 적용하되 기본 슬리퍼로 모두 클리어할 수 있게 한다.

## Source of Decisions

- [확정 결정서](../decisions/2026-10-22-corgi-outfits-paint-and-bosses.md)의 D01~D09. 사용자 선택이 계획자의 세부 수치보다 우선한다.
- 기존 월드 2 치즈 태비 아트는 이미 제작되었으므로 전투에 재사용한다. 별도 [월드 2 맵 2·3 계획](./2026-10-21-world02-three-playground-maps.md)은 미실행 상태로 유지하며 파일 충돌 시 완료된 실제 코드를 기준으로 통합한다.

## Dependencies and Boundaries

- P01의 맞춤 흰 옷 마스크 → P02의 사용자 그림 출력 → P04의 보스전 착용 표시 순서로 구현한다.
- P04의 월드 2 보스 전투는 기존 보스 스테이지에서 단독 검증할 수 있다. 월드 2 맵 2·3의 정상 이동 경로는 별도 계획 실행에 달려 있으며 이번 계획에서 그 맵을 중복 제작하지 않는다.
- 월드 3의 네 일반 스테이지는 실제 공사장 바닥·배경·장애물·체크포인트·출구까지 만든다. 월드 4·5 일반 맵의 완전한 신규 지형 제작은 이 결정서에 포함되지 않았다. 보스 스테이지는 단독 진입과 전투·클리어를 검증한다.
- 최종 보스 승리 후 기존 엔딩 컷신을 연결한다. 후속 스킬의 실제 사용 효과 추가는 별도 요청 대상으로 남긴다.

## Completion Criteria

- 픽셀 의상과 장신구가 걷기 4프레임·짖기 1프레임, 방향 반전에서 몸과 어긋나지 않는다.
- 구버전 저장을 불러와도 코인·장비·클리어가 보존되며, 사용자 옷 3벌의 저장·교체·삭제 없는 덮어쓰기·장착·해제가 새로고침 후 유지된다.
- 월드 3의 네 일반 스테이지가 공사장 주제이며 점프 가능한 장애물, 체크포인트, 출구를 갖는다.
- 보스 2~5가 정해진 HP·주기·고유 패턴으로 싸우고, 슬리퍼와 고급 무기 모두 명중당 피해가 정확하다. 월드 1 재도전도 새 피해량을 사용한다.
- 보스 사망·재도전·일시정지·상점 진입·스킬 짖기·최종 승리 흐름에 게임 정지나 이중 보상이 없다.

## Execution Rule

`.memory/current.md`의 Task부터 한 번에 하나씩 구현·검증·한국어 커밋한다. 각 Task의 커밋 본문에 이 Plan·Phase·Task 식별자를 넣는다. 현재 작업 트리의 다른 미완료 변경은 임의로 되돌리거나 커밋하지 않는다.

UI 코드를 수정하는 Task를 시작할 때는 저장소 `AGENTS.md` 지시에 따라 먼저 `node_modules/next/dist/docs/`의 해당 Next 16 가이드를 읽는다.
