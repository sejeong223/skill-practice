# Plan: 월드 3 안전 콘·시멘트 포대 히트박스 보정

## Goal

월드 3 일반 스테이지 1~4의 안전 콘과 시멘트 포대가 실제 픽셀 윤곽보다 가로로 넓게 충돌하는 체감을 줄인다. 두 물체의 위·중간·아래를 서로 다른 폭의 직사각형으로 나누되, 바닥의 넓은 부분과 기존 접촉 즉시 사망 규칙은 유지한다.

## Scope

- 두 PNG 자체, 1.25배 표시 크기, 각 스테이지의 장애물 8자리·종류·코인·꺼지는 바닥은 유지한다.
- 안전 콘·시멘트 포대에만 원본 PNG 좌표 기준 높이별 충돌 영역을 적용한다. 나머지 4종, 굴러가는 드럼통, 철골 빔, 보스 벽돌, 코기 몸체 판정은 변경하지 않는다.
- 수동 화면 확인은 자동 검사와 구분해 기록한다. 픽셀 단위 완전 일치가 아니라 상·중·하의 폭을 맞춘 단계형 판정이다.
