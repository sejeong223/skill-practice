# Plan: 월드 3 공사장 장애물과 철골 빔 낙하

> 2026-10-27 후속 변경: 기존 계획의 케이블 드럼은 금속 드럼통(`drum-barrel`)으로 교체했다. 기존 배치와 굴러오는 동작은 유지한다. 아래 완료된 Task 청사진은 당시 구현 기록이다.

> 2026-10-28 후속 변경: 철골 빔의 파훼법은 빠른 뒷걸음질이다. 코기의 몸 앞쪽이 낙하 범위에 닿을 때 빔이 작동하며, 즉시 왼쪽으로 돌아서면 피하고 계속 전진하면 맞는다.

## Goal

월드 3 일반 스테이지 1~4의 기존 장애물 8자리에서 케이블 드럼과 손수레를 섞어 배치한다. 드럼은 코기가 240px 이내에 오면 왼쪽으로 초당 160px, 최대 160px 굴러오고, 손수레는 고정한다. 두 물체는 접촉 즉시 사망을 일으킨다. 별도로 짧은 H형 철골 빔을 예고 없이 고정 위치에 한 시도당 한 번, 초당 1,600px로 떨어뜨린다. 두 기믹 모두 재시작과 체크포인트를 지키고, 기존 코인 15개의 ID·보상, 꺼지는 바닥, 보스전을 유지한다. 사용자의 추가 요청에 따라 이전 배경 크기를 기대하는 공사장 에셋 테스트도 현재 자산 계약에 맞게 고친다.

## Sequence and dependencies

1. P00-T01: 사용자가 먼저 요청한 월드 3의 숨은 꺼지는 바닥을 완성한다. 구멍 바로 앞에서만 발동하고 실제 낙사·재시작이 가능해야 한다.
2. P01-T01: 드럼·손수레·철골 빔 이미지와 로드 계약을 완성한다.
3. P01-T02: 새 지상 장애물을 8자리 안에 배치하고 드럼의 이동·재시작을 구현한다. T01 이미지 키를 사용한다.
4. P01-T03: T02의 최종 장애물·코인 배치에서 떨어지는 빔의 안전한 고정 좌표를 적용하고, 낙하·충돌·체크포인트를 구현한다.
5. P01-T04: 기존 공사장 자산 테스트의 낡은 크기 기대값을 현재 이미지에 맞추고 새 위험물까지 검사한다.

각 Task는 자체 검증 후 청사진의 한국어 커밋 메시지로 한 번씩 커밋한다. 작업 트리에 이미 다른 변경이 있으므로 해당 Task의 변경만 선별 스테이징하고 `git diff --cached`를 확인한다.
