# Plan: 픽셀 시네마틱 인트로와 전체 창 화면

## Goal

인트로를 35~40초 길이의 실제 Phaser 장면으로 다시 만들어, 한 공간 안에서 주인·코기·턱시도 고양이·왕갈비뼈가 움직이고 카메라가 이를 따라가도록 한다. 이야기와 11개 사건 순서, 인트로 뒤 타이틀·코기 이름 입력 흐름은 보존한다. 장면·대사·버튼·타이틀은 픽셀 스타일로 통일하고 게임 화면은 브라우저 콘텐츠 뷰포트를 채운다.

## Non-negotiable decisions

- 사용자 승인 전에는 컷신 구현을 시작하지 않는다. P01-T01에서 집 배치와 핵심 네 장면의 픽셀 미리보기를 먼저 보여주고, 승인 대기 중에는 포인터를 T01에 둔다.
- 11개 기존 비트와 대사 순서를 바꾸지 않는다. 총 재생 시간은 약 36.5초를 목표로 하며, 배우는 자막과 대사 표시 중에도 움직인다.
- Phaser의 논리 해상도는 1280×720으로 유지한다. 전체 뷰포트 안에서 캔버스와 DOM 오버레이가 같은 16:9 프레임을 공유한다. 16:9에서는 전체 창을 채우며, 다른 화면비에서는 늘이거나 자르지 않고 테마색 레터박스를 둔다.
- 브라우저 전체화면 API는 호출하지 않는다. 별도 브라우저 헤더, 최대폭 1280px, 바깥 여백은 제거한다.
- 한글 포함 Galmuri 로컬 폰트와 라이선스를 사용한다. 폰트 로드 실패나 지원하지 않는 글리프로 일반 시스템 폰트가 노출되지 않도록 검증한다.
- 첫 재생은 자동 재생하고 건너뛰지 못한다. 이미 본 인트로를 재생할 때만 건너뛰기를 허용한다.
- 미구현인 프레임 애니메이션과 실내 아트는 승인된 미리보기를 토대로 만든다. 코기/턱시도 고양이 외형은 저장소의 승인된 참고 에셋과 일치시킨다.
- 현재 진행 중인 World 1 T05 맵 검수·실제 플레이테스트는 미완료 상태로 보존한다. 이 인트로 계획의 일부로 바꾸지 않으며, 인트로 작업 뒤 사용자와 함께 재개한다.

## Execution order

1. P01-T01에서 장면 미리보기를 보여주고 사용자 승인을 기다린다. 수정 의견이 오면 미리보기를 조정하고 다시 확인한다.
2. 승인 뒤 P01-T02에서 고정폭 페이지를 전체 뷰포트 셸로 바꾸고, 픽셀 폰트 기반을 만든다.
3. P02-T01에서 승인된 스타일을 제작용 배경·배우·소품 픽셀 자산으로 확장하고 PreloadScene에 등록한다.
4. P02-T02에서 별도 IntroScene과 배우 동작 실행기, 컷신 타임라인, 카메라 이동을 연결한다.
5. P02-T03에서 한 글자씩 진행되는 픽셀 자막·대사, 칩튠 큐, 타이틀·이름 입력·World 1 전환을 연결한다.
6. P02-T04에서 첫 재생/재시청, 전체 창 화면비, 시각·음향, 인트로 다음 화면, 캠페인 회귀를 검증한다.

## Scope boundaries

- 이 계획은 집 인트로, 전체 뷰포트 표시, 인트로 텍스트·타이틀·이름 입력에 한정한다.
- World 1 맵과 기믹 디자인 변경, 그 다음 월드 설계, 엔딩 컷신의 시각 재구성은 포함하지 않는다.
- 게임 전체를 브라우저 OS 전체화면으로 강제하거나 모바일 조작 체계를 추가하지 않는다.
- 다른 컷신이 공유하는 CutsceneDirector를 무관한 월드/보스/엔딩 동작까지 포함해 전면 재작성하지 않는다.

## Definition of done

- [ ] 승인된 집 구도와 코기·고양이 디자인으로 11개 비트가 실제 움직이는 Phaser 장면에서 재생된다.
- [ ] 첫 재생은 약 36.5초 자동 재생되고, 장면·자막·대사·타이틀·입력 UI가 픽셀 스타일로 일관된다.
- [ ] 컷신 종료 후 타이틀과 이름 입력이 나타나며, 확인하면 World 1 첫 스테이지로 진입한다.
- [ ] 16:9에서는 캔버스와 오버레이가 뷰포트 전체를 채우고, 비표준 화면비에서도 잘림·늘어짐·레이아웃 불일치가 없다.
- [ ] lint, production build, World 1 map validation이 통과하고 브라우저에서 콘솔 오류 없이 재생된다.
- [ ] World 1 T05는 사용자 맵 검수 전까지 계속 pending으로 남고 완료 처리되지 않는다.
