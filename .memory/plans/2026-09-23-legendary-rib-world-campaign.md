## Goal

월드 하나를 설계·구현·수동 플레이테스트·완료 판정까지 끝낸 뒤 다음 월드로 넘어가는 순차 캠페인을 만든다. 각 월드는 일반 스테이지 4개와 보스 스테이지 1개로 구성하며, 일반 스테이지의 진입·탈출 안전 구간을 제외한 구간에는 학습보다 암기와 정밀 조작을 요구하는 즉사 기믹을 30개 이상 배치한다.

첫 대상인 World 1 `무법지대 뒷골목`은 최소 54개 기믹 배치를 사용한다. 땅 꺼짐·땅 솟음·도달 시 드러나는 백색 가시·점프 시 출현하는 비둘기는 각각 8개 이상 반복하고, 개미·전방 점프 투명 벽·가짜 왕뼈 코인 3종·가짜 체크포인트·상자 고양이 팔·구름 폭우·이름 말풍선 통제불능을 서로 다른 위치와 연쇄 조건으로 재사용한다.

## Non-negotiable Rules

- 모든 일반 스테이지는 `3840×720`을 기본으로 하고, 강제 상승 세트피스가 있는 World 1 stage 2·4는 `3840×1152`까지 허용한다.
- 일반 스테이지는 `192 / 1152 / 1152 / 1152 / 192px`의 5개 구간을 사용한다. section 1과 5에는 lethal trap, forced movement, blocking chain을 배치하지 않는다.
- 실제 분기·지름길은 없다. 화면상 수직 이동도 반드시 메인 루트의 일부이며, 수집품은 메인 루트를 막지 않는 짧은 위험 포켓에만 둔다.
- 즉사 기믹에는 플레이 중 사전 힌트, 경고음, 경고 애니메이션, 색상 강조를 주지 않는다. 사망 후 재시도에서 위치와 조건을 기억해 파훼한다.
- 스킬과 공격·방어 도구는 전투용이며 맵 통과의 필수 조건으로 사용하지 않는다.
- 가짜 체크포인트는 체크포인트 저장을 수행하지 않는다. 진짜 체크포인트는 일반 스테이지마다 1개이고 section 3과 4의 경계에 둔다.
- 다음 월드는 이전 월드의 모든 일반 스테이지, 보스, 검증, 수동 플레이테스트가 완료되고 사용자가 맵을 확인한 뒤에만 시작한다.

## Execution Order

1. P01에서 공통 기믹 계약과 World 1의 구체적인 함정 카탈로그를 먼저 확정한다.
2. P01의 픽셀 에셋, 4개 일반 Tiled 맵, 조작 파훼 런타임, 턱시도 초소 보스를 순서대로 구현한다.
3. P01 수동 플레이테스트에서 각 기믹의 무힌트 즉사, 파훼 조작, 체크포인트 복구, 안전 진입·탈출을 확인한 뒤에만 P02를 활성화한다.
4. P02~P05는 각 월드마다 동일한 `설계 승인 → 에셋·맵 구현 → 런타임 연결 → 보스·검증` 순서를 반복한다.
5. P06에서 전체 25개 스테이지, 5개 보스, 월드 간 스킬 해금·코인 이월·사망 카운트·엔딩 흐름을 통합한다.

## Definition of Done

- [ ] 각 월드가 최소 30개 이상의 기믹 카탈로그와 각 기믹의 명시적인 파훼 조건을 가진다.
- [ ] World 1 일반 4개와 보스 1개가 순서대로 실행되며, 사용자가 확인하기 전 P02로 진행하지 않는다.
- [ ] 즉사 기믹은 첫 노출 때 힌트를 주지 않고, 죽음 횟수·사망 원인·체크포인트 복구가 기록된다.
- [ ] 땅 꺼짐·땅 솟음·백색 가시·비둘기 기믹이 각 월드에서 반복적으로 등장하고, 월드별 사물 변형이 서로 다르다.
- [ ] `npm.cmd run lint`와 `npm.cmd run build`가 통과하며, 모든 월드에서 map validation errors가 0이다.
