# Plan: 월드 2 놀이터 점프 장애물 8종

## Goal

월드 2 첫 스테이지의 연속 모래 바닥 위에 서로 다른 픽셀 장애물 8종을 배치한다. 코기는 각 장애물을 점프로 넘을 수 있고, 접촉하면 체크포인트에서 다시 시작한다. 잠자는 고양이는 접촉 직후 소리와 할퀴기 연출을 보여준다.

## Confirmed Decisions

[2026-10-20 결정](../decisions/2026-10-20-world02-playground-jump-obstacles.md)을 따른다. 고양이를 제외한 7종도 접촉 시 사망하는 것은 사용자가 확정했다.

## Task Order

1. **T01**: 놀이터 색감에 맞춘 투명 PNG 9장과 필수 에셋 등록.
2. **T02**: 월드 2 첫 스테이지에 8종을 놓고 7종의 접촉 사망을 연결. 임시 사각형 함정·적을 제거.
3. **T03**: 잠자는 고양이의 소리·할퀴기·지연 사망을 연결.
4. **T04**: 실제 플레이에서 8종 회피 가능성, 체크포인트, 일시정지, 모바일 화면을 검증하고 필요한 충돌·간격 조정.

## Out of Scope

월드 2 스테이지 2~4의 새 Tiled 맵, 스프링 탈것 물리, 보스전, 새 스킬 효과. 이 계획의 장애물은 첫 스테이지의 임시 맵 경로에 붙인다.
