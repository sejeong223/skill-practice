# Plan: 코기 물기 전신 스프라이트

## Goal

E 물기 때 기존 코기 얼굴과 물기 얼굴이 겹쳐 보이는 현상을 없앤다. 물기 네 프레임을 몸·발·꼬리까지 포함한 전신 이미지로 만들고, 320ms 동안 코기 본체 한 장으로 재생한다. 기본 코기·상점 의상·직접 그린 의상에서 같은 동작을 표시한다. 물기에 짖기와 다른 전용 효과음을 적용하며 기존 명중 판정, 피해, 쿨타임과 장비 표시를 유지한다.

## Sequence and dependencies

1. P01-T01: 기존 코기와 같은 좌표계로 전신 4프레임 PNG를 제작하고 이미지 계약을 검증한다. `corgi-bite` 키는 유지한다.
2. P01-T02: 상점 의상 5종과 직접 그린 의상용 흰색 템플릿의 전신 물기 시트를 제작해 옷·후드·발 위치를 검증한다.
3. P01-T03: 각 의상 물기 시트를 연결하고 `PlayerAnimator`의 얼굴 오버레이를 제거해 본체 텍스처를 전환한다. 장신구·중단 경로를 검증한다.
4. P01-T04: 전용 물기 WAV를 제작해 피드백 에셋으로 로드하고 `bite-hit`의 재생 키를 짖기에서 물기로 변경한다. 성공·거절·일시정지·잠금·장면 종료 경로를 검증한다.

각 Task는 자체 검증 뒤 청사진에 적힌 한국어 메시지로 한 번씩 커밋한다. 기존 작업 트리에는 별도 보스·UI 변경이 있으므로 Task 관련 파일만 선택해 스테이징한다. 이번 단계에서는 구현 코드를 작성하지 않는다.
