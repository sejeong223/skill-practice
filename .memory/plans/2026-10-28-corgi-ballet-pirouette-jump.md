# Plan: 코기 발레 피루엣 점프

## Goal

일반 점프를 시작하면 기존 코기의 비율·색·안광 없는 눈을 유지한 새로운 전신 발레 자세가 세로축으로 한 바퀴 회전한다. 0.6초 뒤에는 옆모습 발레 자세를 유지하고 착지 시 달리기·대기로 돌아간다. 착용 의상·색칠 의상·장신구를 회전 전 방향에서 표시하며, 공중 스킬의 실제 효과와 기존 점프 물리·공격 방향을 보존한다. 더블 점프 기능 자체는 연결하지 않고, 향후 두 번째 점프가 발생하면 같은 회전을 다시 시작하는 이벤트 경로만 준비한다.

## Scope Boundary

- 회전 각도별 전신 코기를 새로 제작한다. 가로 코기 몸통이나 얼굴을 단순히 덧붙인 이미지는 완료 기준을 충족하지 않는다.
- 착용 외형과 사용자 색칠 의상이 점프 중 사라지지 않아야 한다. 별도 튀튀·발레슈즈는 추가하지 않는다.
- `SkillSystem`의 더블 점프 정의에 재시작 이벤트는 연결하되, `StageScene`에서 더블 점프 입력을 새로 활성화하지 않는다.
- 기존 작업 트리의 보스·HUD·월드 3 변경은 건드리지 않는다. Task마다 지정 파일만 스테이징한다.
