# Plan: 월드 3 오후 공사장 맵 아트 개선

## Goal

월드 1의 뒷골목과 월드 2의 놀이터 배경을 시각 기준으로 삼아 월드 3 일반 스테이지 1~4와 고등어 보스 아레나의 공사장 배경·바닥·소품을 다시 제작한다. 실제 1280×720 플레이 화면에서 오후 3~4시의 **밝은 파란 하늘과 따뜻한 측면 햇빛**이 읽히고, 각 구역의 공사장 시설이 구분되며, 코기·코인·점프 장애물이 배경과 혼동되지 않는 것이 완료 기준이다. 석양·야간 연출은 사용하지 않는다.

## Decision Basis and Visual Audit

- 사용자 요청: 월드 1·2의 맵 퀄리티를 참고해 월드 3 디자인을 개선하고, 시간대를 오후 3~4시로 맞춘다.
- 기존 결정 [월드 3 공사장 설정](../decisions/2026-10-22-corgi-outfits-paint-and-bosses.md): 월드 3은 공사장, 보스는 고등어다. 네 스테이지 이름과 진행 구조는 유지한다.
- `world-01-far.png`/`world-01-mid.png`는 2172×724의 도시 원경과 상세한 지붕·전선·빨랫줄을 쌓는다. `world-02-far.png`/`world-02-mid.png`는 1672×941의 구름·나무·놀이기구를 투명 레이어로 쌓는다.
- 현재 `world-03-far.png`와 `world-03-mid-{1..4}.png`는 모두 960×720이며 단색 하늘, 반복되는 사각 건물, 가는 크레인·비계 도형이 대부분이다. 실제 `world-03-stage-1` 화면에서도 명도·형태·깊이 차이가 부족하다. 전경은 거의 빈 960×720 이미지에 하단 경계선만 있다.
- `ParallaxRenderer.render`는 월드 3 텍스처를 `tileSprite`로 가로 반복하고 높이를 720에 맞춰 확대·축소한다. 새 배경은 1672×941을 표준으로 삼아 화면상 약 1280px 폭이 한 반복 주기가 되게 하고 좌우 이음새를 검사한다.
- 네 일반 스테이지는 `getWorld03StageTheme`가 중경을 선택한다. 보스 스테이지는 해당 분기에 없어 등록되지 않은 기본 `world-03-background-mid`가 색 사각형으로 대체된다. 보스용 중경을 별도 제작·연결한다.
- 충돌 바닥 상단은 y=504, 기존 바닥 그림 시작은 y=499다. 기존 장애물 위치·충돌 박스·체크포인트·출구·보스 패턴은 시각 개선 과정에서 변경하지 않는다.

## Scope

- 포함: 오후 하늘 원경, 공통 전경과 바닥, 네 구역별 중경, 보스 중경과 바닥, 공사장 장애물 네 종류의 외형, 월드 3 팔레트·에셋 등록·레이어 선택, 시각 및 기존 플레이 검증.
- 제외: 맵 길이·점프 난도·장애물 좌표/충돌·컷신 재생 흐름·보스 공격 로직·월드 1·2 이미지 변경.
- 사용자 확인: 재생 경로에 연결되지 않은 `world-03-intro`와 존재하지 않는 선택형 `world-03-map-placeholder` 정리는 이번 디자인 계획에 포함하지 않는다.
- 기존 미커밋 작업이 `StageScene.ts`, `worlds.ts` 등에 있다. 실행자는 파일 전체를 되돌리지 않고 해당 심볼만 수정하며 변경 전후 `git diff`로 기존 작업 보존을 확인한다.
