# Plan: 월드 3 공사장 인트로

## Goal

월드 2의 전용 인트로 흐름을 따라 오후 3~4시 공사장 픽셀 화면, 확정된 나레이션·코기 대사 6개, 공사장 음악과 짧은 드릴·굴착기 효과음을 보여준다. 일반 진행과 개발 모드에서 월드 3 첫 진입에만 인트로를 재생하고, 종료 후 `world-03-stage-1`을 시작한다.

- 월드 3 인트로의 여섯 줄 문구와 순서는 바꾸지 않는다. 기존 `world-03-intro` 임시 항목은 교체하며 중복 ID를 만들지 않는다.
- 월드 2 인트로, 월드 3 스테이지 물리·장애물·전투·맵 배경은 변경하지 않는다.
- 인트로 초상화에는 장착 의상을 그리지 않는다. 기존 코기 얼굴 비율과 안광 없는 눈을 따른다.
- 사용자 선택에 따라 등록만 되어 있고 실제 파일·코드 참조가 없는 선택형 `world-03-map-placeholder`를 T01에서 제거한다. 다른 월드의 선택형 항목은 건드리지 않는다.
