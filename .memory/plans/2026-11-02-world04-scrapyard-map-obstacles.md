## Goal
월드 1~3의 픽셀 스타일을 이어받은 노을빛 고물상 일반맵 4개를 만든다. 지상 사물 7종·공중 사물 3종과 별도 바닥 함정 2종을 배치하고, 대시가 필요한 고난도 경로를 실제 조작으로 통과할 수 있게 한다. 무전조 상승 바닥은 후퇴로만 피하고 한 시도에 한 번 작동한다. 일반맵마다 x=2496의 체크포인트 1개를 사용한다.

## 사용자 추가 지시

- 후속 실행 스킬에 별도 검증 기록 경로 관례가 있어도 이 사용자 지시를 우선한다.

- 검증 커맨드·결과·수동 확인 한계는 각 Task의 Validation/Progress에 기록한다. 화면 캡처가 필요하면 운영체제 임시 폴더의 개별 파일을 사용하고 저장소에 테스트 결과 폴더를 만들지 않는다.
- 기존 월드 3 인트로 자동 진행 중단 기록은 사용자 답변에 따라 별도 후속 작업으로 유지한다.
- 현재 단계의 출력은 이 계획·Phase·Task 문서·current.md뿐이다. 구현·에셋 생성·커밋은 실행 단계에서 한다.

## 작업 단위의 근거
단일 Phaser 기능이므로 Phase를 인위적으로 나누지 않는다. 데이터·아트·독립된 동작 시스템까지는 새 파일을 검증하고, 모든 동작이 준비된 T07에서만 실제 일반맵을 교체한다. 지상 시스템과 이동 제어 변경은 같은 Task에 두어 컨베이어 속도가 다음 프레임에 지워지는 불완전한 상태를 피한다. 각 Task는 관련 검증과 함께 독립적으로 커밋한다.

## 구현 경계
- 월드 4의 world-04-stage-1~4만 새 코드 기반 지형을 사용한다. 일반맵에 Tiled 파일을 새로 만들지 않는다. 기존 placeholder 타일맵이 실수로 선택되지 않도록 T07에서 분기한다.
- 사물 10종과 바닥 2종은 서로 다른 목록이다. 네 맵의 장애물 개수는 동일하지 않아도 된다.
- 현재 월드 4의 공용 샘플 함정·적·발판을 새 지형과 중복 생성하지 않는다. 월드 1~3·보스·월드 5의 생성 경로는 월드 4 일반맵 판별 함수로 분리한다.
- 코인 15개 및 기존 segment 기반 코인 ID·경제 규칙을 유지한다. 좌표는 안전한 지점으로 이동하고 기존 뼈 코인 그림을 사용한다.
- 새 저장 스키마나 서버/API/외부 패키지는 도입하지 않는다. 세션 내 체크포인트 사망 복원과 기존 resumeCheckpointId 진입을 연결한다. 브라우저 재접속에 월드 4 체크포인트를 영구 저장하는 신규 기능은 이번 요구가 아니다.
- 대시 480px/s·250ms·쿨타임 1400ms, 이동 240px/s, 점프 -473px/s·중력 1200px/s², 코기 몸 72×40px를 기준으로 한다. 더블 점프나 새 조작키를 요구하지 않는다.
- 물리 치수·좌표·초기 주기는 Task에 명시한다. 실제 Phaser 검증에서 불가능한 경로가 확인되면 T08에서 수치만 조정하고 이유와 바뀐 값을 해당 Task에 남긴다. 무전조·후퇴 전용·1회 작동·7+3 종류·즉사 분류는 수치 조정 대상이 아니다.

## 기술 구조
1. world04Types.ts / world04Scrapyard.ts: 불변 설정과 네 맵의 배치.
2. world04Geometry.ts 및 각 State 모듈: Phaser를 import하지 않는 좌표·시간·충돌 계산.
3. Terrain/Ground/AirSystem: 계산 결과와 실제 그림·물리 바디 연결.
4. World04HazardSystem: 이동 표면 샘플링, 세 시스템 업데이트, 일시정지·사망·재시작·해제의 단일 소유자.
5. StageScene: 기존 입력·대시·체크포인트·사망 이벤트 경로와 연결. 캐릭터의 시각 포즈/의상 기능을 복제하지 않는다.

## 주요 회귀 방지
- DeathSystem은 death-requested 처리 안에서 동기적으로 부활시킨다. 이전 시도의 나머지 충돌 루프가 새 시도를 죽이지 않도록 세대 번호와 즉시 반환을 사용한다.
- 상승 바닥은 숨은 즉사 영역으로 판정하지 않는다. 앞쪽의 높은 판이 길을 막고 뒤쪽 판이 실제로 치솟기 전에 후퇴하게 한다. 점프/전방 대시 우회와 생성 첫 프레임 즉사를 모두 검증한다.
- 꺼지는 바닥을 제거해도 보이지 않는 원래 통바닥 충돌체가 남으면 낙사가 불가능하다. 처음부터 구간별 지형을 소유한다.
- 대시 무적은 전기·추·톱에만 적용하고 압사·낙사·고철·상승 바닥에는 적용하지 않는다.
- 모든 새로운 시간은 플레이 중 경과 시간으로만 누적한다. Scene.time 타이머나 Tween이 일시정지 중 독립 진행하지 않게 한다.
- 체크포인트는 점프·대시로 깃발 위를 지나도 획득되며, 부활 시 이동 효과·바닥/기계 상태와 이전 프레임 충돌 위치를 초기화한다.
- 배경은 플레이 바닥을 그려 넣지 않고, 함정 위치를 암시하는 균열도 그리지 않는다. 입구·출구·체크포인트·후퇴 공간은 위험물 궤적에서 분리한다.

## Validation Strategy
각 Task의 정확한 커맨드와 사례를 사용한다. 자동 검증 파일은 scripts/ 바로 아래에만 추가한다. T07에서 타입·린트·빌드를 통과시키고 T08에서 실제 입력을 사용하는 브라우저 통과·사망·일시정지·복원을 확인한다. 텔레포트는 구간 준비에만 사용하며 그것을 클리어 증거로 기록하지 않는다. 계획 작성 시에는 게임 테스트를 실행했다고 주장하지 않는다.
