# 전투 종료 위치 고정 검증

- 대상: P01/T01, `StageScene.holdPlayerForVictoryDialogue` 및 마지막 타격 프레임 종료.
- 자동 47건, `npx.cmd tsc --noEmit`, `npm.cmd run lint`, `npm.cmd run build` 통과.
- 별도 Chromium 저장 컨텍스트에서 실제 이동키+J 공격으로 마지막 타격. 보스 HP1과 공격 직전 위치만 fixture로 준비했다. 물리와 렌더러는 정상 실행했다.
- [측정 결과](./assets/world01-victory-dialogue-position.json): 좌측 지상 x1200/y504, 우측 지상 x1360/y504, 공중 x1200/y483.667. 첫 대사와 직전 좌표가 같고 이후 최대 x/y 변화 모두 0px. 세 경우 모두 3.2초 이상 입력을 유지했다.
- 첫 대사부터 body 비활성·속도0·idle·표시/활성 유지. 달리기 애니메이션·슬리퍼·방패 표시 종료. 화자 전환에 따라 카메라는 이동하고 줌1을 유지했다.
- 자동 8개 대사, Space/Enter 수동 진행, 재시청 건너뛰기에서 완료/클리어 이벤트 각각1회, 짖기 보상1개, 사망 증가0.
- 세 경우 모두 월드2 진입 후 새 body 활성화·오른쪽 이동·점프 상승을 확인했다. 대화 중 씬 재시작도 새 보스 HP10/물리 활성/조작 가능. 패배 시 4단계 깃발 x2329로 복귀했다.
- 브라우저 pageerror 0건. 확인 환경은 데스크톱 Chromium이며 실제 모바일 터치 조작은 별도로 수행하지 않았다.
- T01 시점 기절 그림은 기존 마지막 대사에서 나타난다. 첫 대사부터 기절시키는 요구는 후속 T02에서 구현·검증한다.
- 요청 범위 밖에서 새로 발견한 결함: 특이사항 없음.
