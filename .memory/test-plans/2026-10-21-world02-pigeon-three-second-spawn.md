# 월드 2 비둘기 3초 등장 검증

- 비둘기 단위 테스트에서 생성 시각 `50/3050/6050ms`를 확인했다. 세 배설·사망·정지·체크포인트 포함 관련 테스트 18건 통과.
- Chrome 실게임에서 첫째와 둘째 비둘기 등장 간격 `3016.5ms`를 측정했다. 첫 비둘기의 세 배설 간격 `833.2/816.7ms`, 세 좌표 `1364/1280/1196px` 유지.
- 일시정지 중 재생성 없음, 고양이 점프 사망 0건, 비둘기 배설 사망 후 체크포인트 부활, 브라우저 오류와 누락 자산 0건 확인.
- 린트, 빌드, 별도 TypeScript 검사 통과.
