# 월드 1 낮 경로·삼색이 보스 플레이테스트 계획

- 상태: T07 실행 및 검증 완료 (2026-09-29)
- 기준: [결정](../decisions/2026-09-29-world01-daylight-calico.md), [실행 계획](../plans/2026-09-29-world01-daylight-calico.md)
- 실행 환경: Windows Edge 헤드리스 750×485 및 375×667, `npm.cmd run dev`. CDP로 실제 방향키·Space·J·ESC·Enter·마우스 입력을 보냈다. 위험별 단독 재현은 개발자 도구로 시작 위치를 맞췄고, 마지막 1→2→3→4→보스 연속 주행은 시작점부터 키 입력만 사용했다. F2와 URL 변경은 완주에 사용하지 않았다.
- 발견·수정: 첫 걷기 검사에서 80px 열린 맨홀을 72px 플레이어 충돌체가 건넜다. 월드 1에서만 충돌체를 발 그림 중심의 48px로 줄인 뒤 두 맵에서 걷기 추락·점프 생존을 재확인했다. 모바일 하트가 일시정지 아래에 놓이던 배치를 수정해 왼쪽에 표시했다. 2단계 첫 지붕 턱 바로 뒤 갈매기 때문에 점프 시점이 좁아져 갈매기를 두 번째 턱 뒤 x2048로 옮기고 뒤 가시·상자·가짜 코인도 간격에 맞게 조정했다. 최종 63.0초 연속 주행에서는 사망 0회였다.
