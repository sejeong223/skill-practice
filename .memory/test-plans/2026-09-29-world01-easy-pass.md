## 수동 확인 방법
1. 개발 화면에서 F2로 일반 1→2→3→4→보스→1 순서를 연다. F3로 맵 개요를 본다.
2. 각 일반 스테이지의 정적 장애물은 화면에 들어올 때부터 보여야 한다. 걸어서 닿으면 기존 사망/재시작을 확인하고, 미리 점프하여 피한다.
3. 가짜 간식 코인은 걷기만 할 때 닿지 않아야 한다. 점프하여 일부러 닿을 때만 종류별 기존 효과를 확인한다.
4. 보스 스테이지는 오른쪽으로 걸어 턱시도 고양이에게 가까이 가서 `J`를 2번 누른다. 고양이는 움직이거나 공격하지 않아야 한다. 승리 전 출구는 잠겨 있고 승리 뒤 출구로 월드 1을 끝낸다.
