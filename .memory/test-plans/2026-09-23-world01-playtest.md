# World 1 — 무법지대 뒷골목 플레이테스트

> 2026-09-29: 아래 표는 기존 66개 돌발 함정 기준의 역사 기록이다. 새 검수 기준은 [월드 1 낮 경로·삼색이 보스 플레이테스트](./2026-09-29-world01-daylight-calico.md)를 따른다.

## Scope

- 대상: World 1 일반 스테이지 1~4 (각 단일 루트 맵)
- 맵 크기: 3840px × 720px (스테이지 2·4는 수직 경로 포함)
- 검증 기준: 진입/탈출 5% 안전 구간, 중간 구간에 힌트 없는 기믹, 8초 이하 기믹 간격
- 자동 검증: `npm.cmd run world01:maps:check`, `npm.cmd run lint`, `npm.cmd run build`
- 개발 중 런타임 검증: F1 진단, F2로 World 1-1~1-4 전환, F3 전체 맵 개요 보기
- 사용자 검수 이미지: `assets/world01-stage{1..4}-entry.png` 및 `assets/world01-stage{1..4}-overview.png`

## Automated verification and visual evidence

- `npm.cmd run world01:maps:check`: 통과 — 일반 맵 4개, 기믹 66개, Tiled 객체 81개; 꺼짐·솟음·백색 가시 각 12회.
- `npm.cmd run lint`: 통과.
- `npm.cmd run build`: 통과.
- `validateCampaignMaps(CONTENT_REGISTRY)`: World 1 일반 맵 4개 모두 errors 0, warnings 0.
- Browser smoke: 인트로/이름 입력 완료, 캐릭터 상태 패널이 스테이지 진입 시 닫혀 있고 상태 버튼으로 열고 닫힘, 좌우 방향키 화면 캡처 완료, 브라우저 예외 0건. 최신 화면: `assets/corgi-walk-stage-final.png`; 좌향 입력 증거: `assets/corgi-walk-left-runtime.png`.
- 코기 걷기 시트: `public/assets/pixel/characters/corgi/corgi-run.png` (4프레임 Phaser spritesheet). 좌우 반전은 기존 입력 컨트롤러의 `flipX` 동작을 사용한다.
- 각 스테이지의 진입 화면과 F3 전체 경로 개요를 캡처했지만, 경로/아트 승인과 실제 플레이 조작 검수는 사용자 확인 대기 중이다.
- 전체 경로 개요는 경로 구조 확인용 개발 화면이다. 반복되는 배경 장식은 숨기고 낮 하늘색 바탕으로 표시한다.
