# 월드 2 치즈 태비 승리 흐름 수동 검증

## 검증할 흐름

- [ ] 첫 보스 진입에서 전투 전 대사 7줄과 화자·카메라를 확인한다.
- [ ] 치즈 태비 HP 0 직후 흰색이 지워지고 왼쪽 얼굴의 쓰러진 프레임이 전투 후 대사 8줄 동안 유지되는지 확인한다.
- [ ] 마지막 대사 뒤 `[STAGE CLEAR!]` → `[SKILL UNLOCKED!]` 물기 → 월드 3 첫 스테이지 순서로 진행한다.
- [ ] 클리어·물기 해금 저장 뒤 재진입 위치를 확인한다.
- [ ] 월드 1 재도전의 짖기 해금 → 클리어 → 월드 2 입장 순서를 확인한다.
- [ ] Q 공격, W 짖기, E 물기 피해 2와 6초 쿨타임, 무는 코기 이미지와 장비 표시를 확인한다.

## 실행 기록

T03~T06 구현 후 실제 브라우저에서 단계별 관찰 결과를 기록한다.
