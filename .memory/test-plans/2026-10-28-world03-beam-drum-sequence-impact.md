# 월드 3 철근·후반 장애물·체크포인트·충돌음 검증

## T01 드럼통 뒤 철근과 후반 장애물

- 구현: 철근 x좌표를 스테이지별 `[1165]`, `[1165, 2340]`, `[1165, 2340, 2900]`, `[1165, 2340, 2880]`으로 변경. 각 스테이지의 기존 장애물 8개 뒤에 x=3400·3550 두 개를 추가.
- 자동 검증: `world03-steel-beams`, `world03-construction-stages`, `world03-construction-obstacles`, `world03-collapsing-floor` 합계 16개 통과. `tsc --noEmit`, 전체 ESLint 통과.
- 수동 검증 한계: 격리된 인앱 브라우저에서 월드 3 인트로 첫 자막 이후 타이머가 진행되지 않았다. 대체 브라우저 접근도 URL 확인 실패로 중단되어 원래 사용자 저장은 건드리지 않았다. 스테이지 1~4의 드럼·철근·연속 점프는 실제 조작으로 확인하지 못했다. T01의 배치·판정·회피·재시작은 위 자동 검증을 완료 기준으로 삼고 이 한계를 남긴다.

## T02 마지막 체크포인트 부활

- 코드에서 확인한 취약점: 체크포인트 활성화가 물리 overlap에만 의존해 공중에서 깃발을 건너뛰면 스냅샷이 비어 있을 수 있었다. `CheckpointSystem.activate`도 스냅샷이 하나라도 있으면 이후 다른 ID를 받지 않았다. 실제 시작점 부활의 원인이 이 경로인지는 수동 재현으로 확인하지 못했다.
- 수정: 월드 3 일반 스테이지에서 코기 중심이 체크포인트 x를 통과하면 기존 활성화 경로를 호출한다. 같은 ID는 한 번만 기록하고, 다른 ID는 최신 스냅샷으로 교체한다.
- 자동 검증: 월드 3 스테이지 1~4의 통과 전/후, 함정·낙사·적 사망, 최근 ID 우선, 기존 월드 회귀를 포함한 21개 통과. `tsc --noEmit`, 전체 ESLint 통과.
- 수동 검증 한계: T01과 같은 브라우저 인트로 정지 및 접근 제한 때문에 깃발 통과와 부활 좌표를 화면에서 재확인하지 못했다. 원래 사용자 저장은 변경하지 않았다.

## T03 철근 충돌음 자산

- 제작: 고정 시드 노이즈 타격, 118→72Hz 저역 충격, 서로 정수배가 아닌 네 금속 공명, 두 잔진동을 합성해 0.85초 mono 44.1kHz/16비트 PCM WAV로 출력했다. 외부 녹음 샘플은 포함하지 않았다.
- 자동 검증: 생성기 `--check`, WAV 형식·진폭·감쇠·오디오 등록 검사 4개, 자산 manifest 검사, 타입 검사와 전체 ESLint 통과.
- 청감 확인 한계: 이 실행 환경에서는 헤드폰/스피커의 실제 재생음을 청취할 수 없어 청감 품질은 직접 검증하지 못했다. WAV 파형의 초기 타격·중간 잔향·후반 감쇠 비율은 자동 검사했다.

## T04 철근 명중·착지 효과음 재생

- 철근이 코기에 닿으면 `player` 충돌 사건을 사망 요청보다 먼저 발행하고, 같은 프레임에 착지하더라도 바닥 충돌 사건은 발행하지 않는다. 코기를 피한 철근은 착지 순간 `floor` 사건을 한 번만 발행한다. 사망 요청에는 철근 ID를 넣어 기존 카툰 사망음을 생략한다.
- 자동 검증: 철근·오디오·사망 관련 테스트 29개 통과. 명중·동시 착지 우선순위·뒷걸음질 회피·잔상·재시작, 버퍼 ID 8·gain 0.52·BGM 0.38 duck/복원·일시정지·폐기·무음 환경을 확인했다. 생성 WAV 일치, 자산 171건, 타입 검사, 전체 ESLint, 배포 빌드 통과.
- 수동 검증 한계: T01과 동일한 브라우저 인트로 정지/접근 제약으로 실제 스테이지 조작 및 스피커 청취를 완료하지 못했다. 실제 음색·볼륨과 드럼통 직후 반응 시간은 사용자 플레이 확인이 남아 있다. 원래 사용자 저장은 변경하지 않았다.

## 후속 수정: 짧고 날카로운 철근 충돌음

- 사용자 청감 피드백: 기존 0.85초 합성음은 `딩~`처럼 부드럽고 길게 들렸다. 이를 실제 철 파이프가 콘크리트에 떨어지는 CC0 녹음의 첫 타격으로 교체했다. 원본 일부를 `art/source/world03-steel-pipe-drop-bibow-cc0.wav`에 보관하고, 0.28초로 잘라 고음을 강조하고 잔향을 빠르게 줄였다. 출처·가공 내용은 `public/assets/audio/ATTRIBUTION.md`에 기록했다.
- 자동 검증: 효과음·재생·철근 판정 테스트 26개, WAV 재생성 일치, 자산 manifest 검사 통과. 시작 30ms의 에너지가 50~100ms의 4배 이상이고 150~250ms의 20배 이상인 것을 확인했다.
- 수동 검증: 이전과 동일하게 실행 환경에서 스피커 청취를 할 수 없으므로 최종 음색은 사용자 플레이로 확인해야 한다.

## 후속 수정: 철근 충돌음 시작과 음량

- 사용자 피드백에 따라 원본 클립의 앞쪽 약 8ms 여백을 건너뛰어 출력 파일의 강한 타격이 시작 후 2ms 이내에 들리도록 조정했다. 해독 완료된 효과음은 충돌 이벤트에서 비동기 대기 없이 즉시 시작하도록 재생 경로를 바꿨다. 철근 충돌음 gain은 0.52에서 0.72로 올렸다.
- 자동 검증: 시작점·gain·동기 시작·일시정지·폐기·철근 단발 충돌 관련 테스트 26개와 WAV 재생성 검사 통과. 실제 스피커 청취와 화면 타이밍 확인은 실행 환경에서 미실시했다.
