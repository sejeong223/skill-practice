- 타입 검사, 변경 파일 lint, 빌드 통과.
- 개발 브라우저 `http://localhost:3001`의 월드 3 공사장 진입로에서 해금된 E 물기를 눌러 HUD가 `준비 → 6.0초`로 바뀌는 것을 확인했다. 동작 중 화면에서 코기 머리와 몸은 한 장으로 보였고 겹친 얼굴은 보이지 않았다. 브라우저 error 로그 0건.

## T04 전용 물기 효과음

- 자체 합성한 `corgi-bite.wav`는 44.1 kHz·16-bit·mono·0.20초 PCM이다. 생성 스크립트 `--check`로 파일 바이트 재현성을 확인했고 짖기 WAV와 내용이 다르다.
- 자동: 오디오·스킬·물기 연출 관련 테스트 24건 통과. `bite-hit`는 물기 버퍼를 한 번 재생하고 W 짖기는 기존 버퍼를 사용한다. 승인 이벤트 없이 `skill-used(bite)`만 발생하거나 일시정지·잠금·폐기·늦은 디코딩 뒤에는 소리를 재생하지 않는다.
- 에셋 검사 145개(필수 126개), 타입 검사, 변경 파일 lint, 빌드 통과.
- 개발 브라우저를 새로고침해 월드 3 화면 로드와 오류 로그 0건을 확인했다. 브라우저 입력으로 재생음을 직접 청음하거나 출력 장치를 통한 음색 차이를 검증하지는 못했다. E 입력 결과도 이번 브라우저 시도에서 확인되지 않아 수동 청음 결과로 간주하지 않는다.

## 사용자 지적에 따른 전신 디자인 재작업

- 앞선 T01–T02의 "run 몸·발 픽셀 유지" 기록과 테스트 기준은 물기 전신 **동작** 요구를 잘못 해석한 결과였다. 해당 통과 결과는 새 자세의 증거가 아니며, 본 섹션의 재작업으로 대체한다.
- 기존 코기 run·bark를 캐릭터 참조로 삼아 웅크림 → 전신 돌진 → 앞발 착지·턱 닫기 → 낮게 복귀하는 네 포즈를 새로 제작했다. 기본 코기, 상점 의상 5종, 직접 그린 의상 템플릿의 몸통·다리·옷이 모두 자세를 따른다. 검은 눈 내부의 밝은 안광을 제거했다.
- `scripts/build-corgi-bite-sprites.mjs --check`는 일곱 시트가 원본 콘셉트에서 동일 바이트로 재생성되는지 확인한다. `corgi-bite-art`와 `outfit-bite-art`는 run과 몸통 실루엣 차이, 네 프레임 차이, 돌진 프레임의 앞다리 전진, 발 높이, 안광 부재, 흰색 직접 그리기 영역을 검사한다.
- 수정 후 관련 자동 테스트 29건, 필수 에셋 126개 검사, 타입 검사, 변경 스크립트 lint, 빌드가 통과했다. 기본·의상 7개 완성 시트를 원본 크기로 확인했다.
- 개발 브라우저에서 월드 3 화면이 로드되고 오류 로그가 없음을 확인했다. 이 테스트 탭의 키 입력은 E/W 모두 HUD에 반영되지 않아 물기 동작의 실제 게임 화면 검증은 완료로 표시하지 않는다. 자동 연출 테스트가 텍스처 전환과 320ms 복귀를 확인한다.
