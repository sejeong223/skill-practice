## 실제 브라우저 스모크 테스트

상태: **미실행 / 미승인**. 이 실행 환경에서는 브라우저 창을 조작하거나 스크린샷을 캡처할 수 없어 실제 애니메이션, 오디오 청취, DOM과 캔버스의 시각 정렬을 통과 처리하지 않는다. `http://localhost:3000` 개발 서버는 이미 실행 중이었고 HTTP/에셋 검사에만 사용했다. 런타임 캡처 파일은 아직 없다.

사용자 브라우저에서 이어서 확인할 항목:

- [ ] localStorage를 비운 첫 실행에서 인트로가 자동 재생되고 `건너뛰기 · ESC`가 숨겨진다.
- [ ] 새 실행에서 인트로가 시작되지만 각 문장/장면은 입력 전까지 멈추고, 사용자의 클릭·Space·Enter로만 진행된다.
- [ ] 타이핑 중 첫 입력은 현재 문장을 완성하고, 다음 입력은 나레이터/인물 대사를 한 줄씩 순서대로 넘긴다. 두 문구가 동시에 보이지 않는다.
- [ ] 11개 비트가 순서대로 한 번만 재생되고 배우 이동/카메라 이동, 갈비뼈 공개 카드, 마지막 페이드가 보인다.
- [ ] 첫 실행 중 포인터 클릭 또는 키 입력 후 이후 효과음/장면별 칩튠이 재생되며, 자동재생 제한이 있어도 콘솔 오류가 없다.
- [ ] 인트로 완료 후 게임 타이틀 화면이 입력 전까지 유지되고, `시작하기`를 눌러야 이름 입력 화면으로 넘어간다. 공백 입력은 `코기`, 앞뒤 공백과 `<`/`>`는 제거되며 이름은 20자로 제한된다.
- [ ] 이름 확인 후 World 1 스테이지 1로 전환되고 이름이 진행 데이터에 저장되며, 상태창은 닫혀 있고 게임 HUD가 보인다.
- [ ] 같은 세이브로 재접속한 재생에서만 건너뛰기 버튼과 Escape가 동작하고, 첫 실행에서는 동작하지 않는다.
- [ ] 슬리퍼를 문 장면에서 첨부 이미지의 코기·소품 일체형 스프라이트가 사용되고 별도 슬리퍼가 겹쳐 보이지 않는다.
- [ ] 각 화면비(1920×1080, 1280×720, 2560×1080, 1280×800)에서 프레임 경계·레터박스·DOM 자막 정렬 및 잘림을 확인한다.
- [ ] 장면 종료 뒤 오디오 반복/이벤트 리스너가 남지 않고 콘솔 오류 및 필수 에셋 404가 없다.
- [ ] World 1 기존 맵 확인을 이어갈 때 `.memory/phases/2026-09-23-legendary-rib-world-campaign/P01-world01-back-alley/T05-world01-validation-and-playtest.md`의 검수 대기 상태가 그대로 유지된다.
