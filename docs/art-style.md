# Pixel Art Style Guide

## 목적

이 문서는 생성형 이미지와 Phaser 런타임 에셋이 같은 작품처럼 보이도록 하는 시각 계약이다. 밝고 유쾌한 2D 만화풍을 유지하되, 모든 캐릭터와 도구에는 선명한 픽셀 클러스터와 제한된 색상을 사용한다.

## Visual Direction

- 전체 분위기: 밝은 2D 카툰 + 살짝 강한 16비트 픽셀 아트
- 논리 타일 크기: 16x16
- 코기 기준 프레임: 32x48 논리 픽셀
- 표시 배율: 2배 또는 3배 정수 배율
- 렌더링: nearest-neighbor, 중간 배율과 흐릿한 보간 금지
- 외곽선: 논리 픽셀 1~2칸의 짙은 색 외곽선
- 명암: 페인터리 그라디언트보다 2~4단계의 색면과 픽셀 클러스터
- 조명: 화면 왼쪽 위에서 들어오는 따뜻한 빛
- 배경: 플레이어와 함정이 잘 읽히는 단순한 형태, 장식은 실루엣을 해치지 않는 선에서 사용

## 캐릭터 계약

### 코기

- 주인공은 통통하고 짧은 다리의 주황색과 흰색 코기다.
- 큰 귀, 둥근 배, 짧고 뭉툭한 꼬리를 핵심 실루엣으로 유지한다.
- 스카프, 목걸이, 상시 착용 장식은 사용하지 않는다.
- 종이 생일 모자는 인트로에서만 등장하며 추격 시작 중 떨어진다.
- 기본 눈은 작은 픽셀 점눈이고, 코와 입도 매끈한 벡터 형태가 아닌 픽셀 형태로 그린다.
- 눈썹은 그리지 않는다.
- 감정 변화는 눈 크기와 하이라이트, 입 모양, 귀 방향, 고개 각도로 표현한다.
- 멍청하지만 사랑스러운 인상을 유지하고, 공포나 분노도 잔혹하게 보이지 않도록 한다.

### 턱시도 고양이

- 검은 털과 흰 가슴, 뾰족한 귀, 가느다란 꼬리로 코기와 실루엣을 구분한다.
- 반쯤 감긴 눈과 짧은 입 모양으로 오만한 표정을 만든다.
- 위협적인 역할이지만 공포물처럼 보이지 않는 만화풍을 유지한다.

## 생성형 에셋 작업 순서

1. 정면, 측면, 후면과 표정이 포함된 레퍼런스 시트를 만든다.
2. 실루엣, 색상, 얼굴 계약을 승인한 뒤 행동 포즈를 만든다.
3. 각 포즈를 32x48 코기 기준 프레임에 맞춰 정리한다.
4. 투명 배경과 일정한 발 위치를 확인하고 불필요한 그림자와 텍스트를 제거한다.
5. 픽셀 클러스터를 정리하고 nearest-neighbor 기준으로 축소한다.
6. Phaser에서 사용할 스프라이트시트 또는 아틀라스로 묶는다.

생성기에는 글자, 로고, UI, 워터마크를 요청하지 않는다. 생성된 텍스트는 런타임 UI에서 별도로 표시한다.

## 애니메이션 규칙

- 코기의 모든 행동 프레임은 발바닥 기준선과 몸의 중심을 맞춘다.
- idle, run, jump, attack, bite, dash, bark, double-jump, tail-rotor, hurt, death의 실루엣은 한눈에 구분되어야 한다.
- 꼬리 회전은 캐릭터 본체를 다시 그리는 대신 별도의 픽셀 잔상과 회전 효과를 사용할 수 있다.
- 효과음과 화면 흔들림은 스프라이트와 분리한다.
- 색상, 귀 모양, 꼬리 길이, 품종 실루엣이 프레임마다 달라지면 해당 프레임을 재생성한다.

## 런타임 분리

- references: 생성형 레퍼런스 시트. 디자인 승인과 후속 생성의 기준이며 직접 플레이에 사용하지 않는다.
- sprites: 실제 플레이용 정리된 프레임과 아틀라스.
- collision: 스프라이트와 독립된 직사각형 또는 캡슐형 충돌 바디.
- ui: 체력, 코인, 죽음 횟수, 장비 정보와 같은 텍스트와 패널.
- vfx: 재채기, 짖기 파동, 밥그릇의 챙 효과, 꼬리 회전 잔상.
